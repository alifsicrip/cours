### 💊 CAT IDE — EIM des psycholeptiques

Les **psycholeptiques** comprennent notamment les **antipsychotiques/neuroleptiques**, anxiolytiques et hypnotiques. Pour une fiche IFSI, les signes les plus importants à connaître sont ceux qui nécessitent une **surveillance clinique et une alerte rapide**. La HAS insiste sur l’information, le dépistage, la surveillance et la sensibilisation des patient·es sous neuroleptiques. [Haute Autorité de Santé](https://www.has-sante.fr/jcms/p_3381939/fr/flash-securite-patient-patient-sous-neuroleptique-la-vigilance-est-la-bonne-pratique?utm_source=chatgpt.com)

| ⚠️ EIM | 👀 Je vois | 👩‍⚕️ CAT IDE |
|---|---|---|
| 🌡️ **Syndrome malin des neuroleptiques** | hyperthermie + rigidité + confusion + sueurs + tachycardie | 🚨 **URGENCE** → arrêter administration selon protocole → médecin immédiatement |
| 🧠 **Syndrome extrapyramidal** | tremblements, rigidité, akinésie, dystonie | 🔎 observer → évaluer → transmettre médecin |
| 👄 **Dyskinésie tardive** | mouvements involontaires bouche/langue/visage | 🔎 repérer + tracer → médecin |
| 😴 **Sédation / somnolence** | baisse vigilance, ralentissement | 🩺 vigilance + FR → prévention chute → transmettre |
| 🧍 **Hypotension orthostatique** | vertiges, malaise au lever | 🪑 asseoir/allonger → TA → prévention chute |
| ❤️ **Troubles du rythme / QT long** | palpitations, syncope, malaise | 🚨 ECG + médecin → surveillance cardio |
| ⚖️ **Syndrome métabolique** | prise de poids, ↑ glycémie, ↑ lipides | ⚖️ poids + 🩸 glycémie/lipides selon prescription → prévention/éducation |
| 🧪 **Hyperprolactinémie** | aménorrhée, galactorrhée, troubles sexuels | 🔎 rechercher → transmettre |
| 🩸 **Neutropénie/agranulocytose** | fièvre, angine, infection inhabituelle | 🚨 NFS → médecin rapidement |
| 🚽 **Constipation / iléus** | constipation, douleurs/distension abdominale, absence de selles | 🔎 transit + abdomen → 🚨 médecin si suspicion iléus |
| 💧 **Rétention urinaire** | difficulté/impossibilité à uriner | 🔎 diurèse + globe → médecin |
| 🤕 **Chutes** | vertiges, sédation, hypotension | 🛡️ sécuriser + prévention chute → rechercher cause |
| 🧠 **Confusion / désorientation** | changement comportemental, désorientation | 🔎 sécuriser → rechercher cause → transmettre |
| 😮‍💨 **Dépression respiratoire** *(surtout sédatifs)* | FR ↓, somnolence profonde | 🚨 **urgence** → FR + SpO₂ → médecin/urgence |   


> **EPS = effets extrapyramidaux** 🧠   
Dans le contexte des **neuroleptiques/antipsychotiques**, ce sont des troubles moteurs liés notamment au **blocage dopaminergique** dans les voies extrapyramidales.  
 🧠 À retenir   
🤕 **Dystonies aiguës** → contractions musculaires involontaires, torticolis, crises oculogyres  
🧍 **Parkinsonisme** → rigidité + tremblements + lenteur des mouvements  
😣 **Akathisie** → impossibilité de rester immobile, agitation motrice  
👄 **Dyskinésies tardives** → mouvements involontaires répétitifs, surtout bouche/langue  
👉 **CAT IDE :** observer → identifier le type de trouble moteur → sécuriser → **prévenir le/la médecin** → tracer.

⚠️ **À ne pas confondre :** le **syndrome malin des neuroleptiques (SMN)** est une complication grave distincte, même s’il peut comporter une **rigidité musculaire**.

### 🧠 À retenir 

**Neuroleptique → 👀 EPS + 🌡️ SMN + ❤️ QT + ⚖️ métabolique + 🩸 NFS + 😴 sédation**

🚨 **SMN = urgence vitale** : **fièvre + rigidité + troubles neurovégétatifs/confusion**.  

La HAS rappelle que les antipsychotiques nécessitent une **évaluation régulière** afin de prévenir les EIG liés notamment aux défauts de surveillance. [Haute Autorité de Santé](https://www.has-sante.fr/jcms/p_3381939/fr/flash-securite-patient-patient-sous-neuroleptique-la-vigilance-est-la-bonne-pratique?utm_source=chatgpt.com)

Pour les **neuroleptiques à action prolongée (NAP)** : vérifier **date de dernière injection + schéma d’administration + traçabilité + signes de surdosage/sous-dosage**. [Haute Autorité de Santé](https://www.has-sante.fr/jcms/p_3599791/fr/label-flash-securite-patient-neuroleptiques-a-action-prolongee-nap-les-nap-parfois-ca-derape?utm_source=chatgpt.com)

## 💊 Psychotropes — Surdosage & sevrage

### 🔴 SURDOSAGE

| Classe | 👀 Je vois | 👩‍⚕️ CAT IDE |
|---|---|---|
| 💊 **Antidépresseurs** | 😴 somnolence/confusion • ❤️ tachycardie • 🩺 hypotension • ⚡ convulsions • ❤️‍🩹 troubles du rythme | 🚨 **urgence** → constantes + conscience + ECG/SpO₂ → médecin/urgence |
| 🧠 **Neuroleptiques** | 😴 sédation • 🧍 hypotension • 🧠 troubles extrapyramidaux • ❤️ QT long • 🌡️ hyperthermie/rigidité | 🚨 sécuriser → constantes + ECG → médecin |
| 😴 **Benzodiazépines** | 😴 somnolence profonde • 😵 confusion • 🫁 dépression respiratoire surtout associations | 🚨 **FR + SpO₂ + conscience** → sécurité voies aériennes → urgence |


> ⚠️ **Toujours rechercher une association** : alcool, opioïdes, autres sédatifs → risque majoré de dépression du SNC/respiratoire.

---

### 🟠 SEVRAGE / ARRÊT BRUTAL

| Classe | 👀 Je vois | 👩‍⚕️ CAT IDE |
|---|---|---|
| 💊 **Antidépresseurs** | 😰 anxiété • 😠 irritabilité • 🤢 nausées • 🌀 vertiges • 😴 troubles sommeil • ⚡ sensations neuro-sensorielles | 🗣️ rassurer → surveiller humeur + risque suicidaire → **arrêt progressif** |
| 🧠 **Neuroleptiques** | 🔄 réapparition/aggravation symptômes psychotiques • agitation • troubles du sommeil | 👀 surveillance clinique → médecin → **ne pas arrêter brutalement** |
| 😴 **Benzodiazépines** | 😰 anxiété/rebond • 😴 insomnie • tremblements • sueurs • agitation | 🩺 surveiller → **sevrage progressif** → médecin |
| 🚨 **Sevrage BZD grave** | 🧠 confusion • hallucinations • ⚡ convulsions • coma | 🚨 **URGENCE / hospitalisation** |



### 🧠 MÉMO 

> **SURDOSAGE → 😴 conscience + 🫁 respiration + ❤️ cardio + 🛡️ sécurité → 🚨 urgence**

> **SEVRAGE → 😰 anxiété + 😴 sommeil + 🧠 neuro/psy → 👀 surveiller → 📞 médecin → ↘️ progressif**

⚠️ **Antidépresseur ≠ dépendance** : un syndrome d’arrêt peut survenir sans qu'il y ait dépendance 

L’ANSM précise que le **syndrome d’arrêt des antidépresseurs** peut apparaître dans les jours suivant l’arrêt, avec notamment anxiété, irritabilité, troubles du sommeil, vertiges et symptômes pseudo-grippaux ; l’arrêt doit être progressif. 

Pour les **benzodiazépines**, la HAS recommande également un arrêt progressif ; un sevrage sévère avec **confusion, hallucinations, troubles de vigilance ou convulsions** nécessite une hospitalisation
