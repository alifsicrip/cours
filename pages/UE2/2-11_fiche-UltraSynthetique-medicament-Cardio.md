# 🫀 FICHE ULTRA-SYNTHETIQUE - MÉDICAMENTEUSE DE CARDIOLOGIE

---

## ❤️ RYTHME CARDIAQUE

🔴 **Amiodarone (Cordarone)**  
💊 Antiarythmique  
🎯 FA / troubles du rythme  
⚠️ Bradycardie – QT long – dysthyroïdie  
👀 **Surveillance IDE :** ECG + FC + bilan thyroïde  

☐  

🟣 **Bisoprolol**  
💊 Bêtabloquant  
🎯 ↓ FC / IC / HTA  
⚠️ Bradycardie – hypotension – fatigue  
👀 FC + TA  

☐  

🔴 **Adénosine (Krenosin)**  
💉 Bolus IV  
🎯 TSV  
⚠️ Pause cardiaque brève (normal)  
👀 Scope + patient rassuré  

☐  

🟤 **Lidocaïne (Xylocard)**  
💉 Antiarythmique  
🎯 TV  
⚠️ Convulsions – confusion  
👀 ECG + neuro  

☐  

🟤 **Isoprénaline (Isuprel)**  
💉 β stimulant  
🎯 Bradycardie sévère  
⚠️ Tachycardie  
👀 FC + TA

## 🩸 ANTITHROMBOTIQUES

🟠 **Lovenox (énoxaparine)**  
💉 HBPM  
🎯 Prévention thrombose  
⚠️ Hémorragie – TIH  
👀 Saignements + plaquettes  

☐  

🟡 **Aspirine Protect**  
💊 Antiagrégant  
🎯 Prévention CV  
⚠️ Ulcère – saignement  
👀 Douleur gastrique  

☐  

🔴 **Brilique (ticagrélor)**  
💊 Antiagrégant puissant  
🎯 Stent / SCA  
⚠️ Dyspnée – hémorragie  
👀 FR + saignement  

☐  

🟠 **Héparine (IV/SC)**  
💉 Anticoagulant  
🎯 Curatif thrombose  
⚠️ TIH – hémorragie  
👀 TCA + plaquettes  

☐  

🟡 **Tirofiban (Agrastat)**  
💉 Antiagrégant IV  
🎯 SCA  
⚠️ Hémorragie  
👀 Saignement  

☐  

🟤 **Protamine**  
💉 Antidote héparine  
🎯 Neutralisation  
⚠️ Hypotension  
👀 TA  

☐  

👉 ⚠️ **ALERTE : TRIPLE RISQUE HÉMORRAGIQUE**  
💥 Aspirine + Brilique + Lovenox

# 🚨 MÉGA SYNTHÈSE (À SAVOIR PAR CŒUR)

🫀 **Rythme :** Amiodarone / Bisoprolol / Adénosine  
🩸 **Thrombose :** Aspirine + Brilique + Héparine  
💧 **IC :** Furosémide + Dobutamine + Dapagliflozine  
⚡ **Iono :** K+ / Mg++  
🧠 **Antidotes :** Naloxone / Flumazénil  

---

# 🎯 RÉFLEXES IDE (NIVEAU EXAM / STAGE)

✔️ FC basse → bêtabloquant / amiodarone  
✔️ Saignement → anticoagulants + AAP  
✔️ TA basse → diurétiques / vasodilatateurs  
✔️ Trouble rythme → kaliémie + magnésium  
✔️ Détresse respi → naloxone
