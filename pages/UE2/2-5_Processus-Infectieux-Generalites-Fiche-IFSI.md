# 🦠 Processus infectieux — Généralités | Fiche IFSI
**UE 2.5 — Synthèse de révision**

## 🧠 Définitions

| Terme | À retenir |
|---|---|
| 🦠 Agent infectieux | Micro-organisme pouvant provoquer une infection : bactérie, virus, champignon, parasite |
| 🧬 Contamination | Entrée d’un agent infectieux dans l’organisme |
| 🧫 Infection | Pénétration et multiplication d’un agent infectieux, avec réaction de l’organisme |
| 🔁 Colonisation | Présence d’un micro-organisme sans signes cliniques d’infection |
| 🤒 Maladie infectieuse | Infection responsable de manifestations cliniques |
| 🚨 Sepsis | Dysfonction d’organe menaçant le pronostic vital liée à une réponse dérégulée à une infection |

## 🦠 Agents infectieux

| Agent | Particularités | Traitement possible selon diagnostic |
|---|---|---|
| Bactéries 🧫 | Certaines font partie du microbiote | Antibiotiques si infection bactérienne sensible |
| Virus 🧬 | Se multiplient dans les cellules de l’hôte | Antiviraux pour certaines infections |
| Champignons 🍄 | Mycoses ou infections invasives | Antifongiques |
| Parasites 🪱 | Vivent aux dépens d’un hôte | Antiparasitaires |

⚠️ **Les antibiotiques n’agissent pas contre les virus.** Le choix du traitement dépend du diagnostic et de la prescription médicale.

## 🔄 Chaîne de transmission

| Maillon | Exemples |
|---|---|
| 1️⃣ Agent infectieux | Bactérie, virus, champignon, parasite |
| 2️⃣ Réservoir | Personne, animal, environnement, eau, aliments |
| 3️⃣ Porte de sortie | Sécrétions respiratoires, sang, selles, urine, lésions |
| 4️⃣ Transmission | Contact direct/indirect, gouttelettes, voie aérienne, sanguine, digestive, vecteur |
| 5️⃣ Porte d’entrée | Voies respiratoires/digestives, muqueuses, peau lésée, sang, dispositif invasif |
| 6️⃣ Hôte réceptif | Susceptibilité variable selon l’état de santé et l’immunité |

## 🛡️ Défenses de l’organisme et facteurs de risque

- **Barrières naturelles** : peau, muqueuses, mucus, cils respiratoires, acidité gastrique, microbiote
- **Immunité innée** : réponse rapide, inflammation, phagocytes, complément
- **Immunité adaptative** : lymphocytes B et T, anticorps, mémoire immunitaire
- **Facteurs de risque** : immunodépression, âge extrême, maladie chronique, dénutrition, plaie, chirurgie, dispositif invasif, vaccination incomplète selon l’infection

## 🤒 Signes cliniques

| Type | Signes possibles |
|---|---|
| Généraux | Fièvre ou hypothermie, frissons, fatigue, altération de l’état général |
| Locaux | Rougeur, chaleur, douleur, œdème, écoulement |
| Selon le foyer | Toux/dyspnée, dysurie, diarrhée, douleur abdominale, plaie purulente |
| 🚨 Gravité | Confusion, polypnée, hypotension, marbrures, oligurie, désaturation, aggravation rapide |

⚠️ L’absence de fièvre n’exclut pas une infection, notamment chez une personne âgée ou immunodéprimée.

## 🧪 Examens et rôle IDE

| Examen | Rôle |
|---|---|
| Examen clinique | Rechercher foyer, signes locaux et gravité |
| NFS, CRP, bilans | Évaluer réponse inflammatoire et retentissement ; résultats non spécifiques |
| Prélèvements microbiologiques | Identifier le germe : hémocultures, urine, prélèvement respiratoire ou de plaie selon prescription |
| Imagerie | Rechercher foyer ou complication |
| Lactate / bilan d’organes | En cas de suspicion de sepsis ou de gravité, selon prescription |

🩺 **Rôle IDE :** vérifier identité et prescription, respecter l’asepsie, prélever au bon moment et dans le bon contenant, étiqueter au lit du/de la patient·e, acheminer rapidement et tracer. En cas de sepsis suspecté, ne pas retarder les traitements urgents pour réaliser les prélèvements.

## 💊 Principes de traitement

- **Anti-infectieux selon la cause** : antibiotiques pour certaines infections bactériennes, antiviraux pour certaines infections virales, antifongiques, antiparasitaires
- **Traitement symptomatique et soutien des fonctions vitales** selon le tableau clinique
- **Contrôle du foyer** si nécessaire : drainage, retrait/remplacement d’un dispositif infecté ou autre geste médical
- **Réévaluation clinique et biologique**, adaptation aux résultats microbiologiques et à l’évolution
- **Bon usage** : respecter indication, dose, voie et durée prescrites ; surveiller efficacité, effets indésirables et allergies

## 🧼 Prévention — rôle IDE

| Mesure | Points clés |
|---|---|
| 🧴 Hygiène des mains | Avant/après les soins et selon les indications |
| 🧤 Précautions standard | Pour tout·e patient·e, tout soin, tout lieu, quel que soit le statut infectieux |
| 😷 Équipements de protection | Gants, masque, protection oculaire/surblouse selon le risque |
| 🧼 Asepsie | Préparation cutanée, technique aseptique, entretien des dispositifs selon protocole |
| 🧺 Environnement | Linge, déchets, matériel et surfaces selon procédures |
| 💉 Vaccination | Selon recommandations |
| 🚪 Précautions complémentaires | Contact, gouttelettes ou air selon agent infectieux et protocole local |

## 🚨 Sepsis : alerte immédiate

**Infection suspectée + apparition d’une dysfonction d’organe = suspecter un sepsis.**

- Signes possibles : confusion, polypnée, hypotension, marbrures, oligurie, désaturation ou aggravation rapide
- Alerter immédiatement le/la médecin ou l’équipe d’urgence
- Évaluer ABCDE, surveiller les constantes, préparer les examens et traitements prescrits
- Ne pas attendre la fièvre, un résultat biologique ou un score isolé
- Le qSOFA ne doit pas être utilisé seul pour dépister le sepsis

## 🎯 Mémo examen

- **Infection = agent infectieux + multiplication + réponse de l’organisme**
- **Colonisation ≠ infection symptomatique**
- **Transmission : agent → réservoir → sortie → transmission → entrée → hôte réceptif**
- **Antibiotiques ≠ antiviraux**
- **Précautions standard à chaque soin, pour toute personne**
- **Infection + dysfonction d’organe = alerte sepsis**
