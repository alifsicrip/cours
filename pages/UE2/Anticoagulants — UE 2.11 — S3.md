# 🩸 Anticoagulants — UE 2.11 — S3

## 🌿 Carte d’identité et grandes familles

Les **anticoagulants** diminuent la capacité du sang à former ou à étendre un **caillot**.

👉 Ils agissent sur la **cascade de coagulation**.

👉 Ils ne « dissolvent » pas directement un thrombus déjà constitué : ils empêchent surtout **son extension et la formation de nouveaux caillots**.

⚠️ À ne pas confondre :

- **anticoagulants** → agissent sur les **facteurs de coagulation** ;
- **antiagrégants plaquettaires** → agissent principalement sur les **plaquettes** ;
- **thrombolytiques/fibrinolytiques** → peuvent favoriser la destruction d’un thrombus.

| 💊 Classe | Exemple | 🎯 Action principale | 💉 Voie |
|---|---|---|---|
| **HNF** = héparine non fractionnée | Héparine sodique | Inhibe plusieurs facteurs, notamment IIa et Xa | 💉 IV principalement |
| **HBPM** | Énoxaparine = Lovenox® | Inhibe surtout le facteur Xa | 💉 SC |
| **AVK** | Warfarine = Coumadine® | ↓ synthèse des facteurs dépendants de vitamine K | 💊 Orale |
| **AOD anti-Xa** | Apixaban = Eliquis®, rivaroxaban = Xarelto® | Inhibition directe du facteur Xa | 💊 Orale |
| **AOD anti-IIa** | Dabigatran = Pradaxa® | Inhibition directe de la thrombine IIa | 💊 Orale |

🎯 Principales situations :

- prévention et traitement de la **TVP** ;
- traitement/prévention de l’**embolie pulmonaire** ;
- prévention des embolies dans certaines **fibrillations atriales** ;
- prévention péri-opératoire selon risque ;
- certaines situations cardiovasculaires ;
- valves mécaniques : **AVK**, et non AOD.

🚨 Risque commun à toutes les familles :

# **HÉMORRAGIE**

## 🧠 Pharmacodynamie : ce que le médicament fait à l’organisme

💡 **Pharmacodynamie = comment l’anticoagulant freine la coagulation.**

Imagine la coagulation comme une **équipe de castors construisant un barrage** 🦫🌊.

Les facteurs de coagulation s’activent les uns après les autres.

Au bout de la cascade :

**facteur Xa → thrombine IIa → fibrine → caillot**

Les anticoagulants retirent certains outils aux castors.

### 💉 1. Héparines → ANTITHROMBINE

Les héparines renforcent l’action de l’**antithrombine**.

L’antithrombine est un frein naturel de la coagulation.

#### HNF

L’héparine non fractionnée inhibe notamment :

**facteur Xa + thrombine IIa**

➡️ ↓ formation de fibrine.

➡️ ↓ extension du thrombus.

Son action IV est **rapide**, ce qui est utile dans les situations aiguës.

#### HBPM

Exemple : **énoxaparine**.

Les HBPM agissent principalement sur le :

**facteur Xa**

🧠 Mémo :

**Héparine → active le FREIN antithrombine 🛑**

### 💊 2. AVK → VITAMINE K

Exemple : **warfarine = Coumadine®**.

La vitamine K participe à la fabrication hépatique de plusieurs facteurs de coagulation.

Les AVK empêchent son action.

➡️ ↓ fabrication des facteurs :

**II + VII + IX + X**

➡️ coagulation ralentie.



🧠 Mémo :

**AVK = Anti-Vitamine K → le foie fabrique moins de facteurs**

⚠️ L’effet n’est pas immédiat.

Les facteurs déjà présents doivent d’abord disparaître progressivement.

### 💊 3. AOD anti-Xa → facteur Xa

Exemples :

- **apixaban = Eliquis®** ;
- **rivaroxaban = Xarelto®** ;
- **edoxaban = Lixiana®**.

Ils bloquent directement le **facteur Xa**.

Donc :

**↓ Xa → ↓ thrombine → ↓ fibrine → ↓ caillot**

### 💊 4. Dabigatran → THROMBINE IIa

Le dabigatran bloque directement la **thrombine = facteur IIa**.

Donc :

**↓ thrombine → ↓ transformation fibrinogène en fibrine → ↓ caillot**

### 🌳 Image mentale

La coagulation est une rivière où l’on construit un barrage :

- 💉 **héparine** → renforce les gardes qui bloquent plusieurs ouvriers ;
- 💊 **AVK** → empêche l’usine de fabriquer certains ouvriers ;
- 💊 **anti-Xa** → bloque l’ouvrier Xa ;
- 💊 **dabigatran** → bloque directement l’ouvrier final IIa.

## 🧪 Pharmacocinétique + LADMER

💡 **Pharmacocinétique = ce que l’organisme fait au médicament.**

| LADMER | 💊 Ce qui se passe | 👩‍⚕️ À retenir |
|---|---|---|
| **L — Libération** | Médicament libéré | Vérifier forme galénique |
| **A — Absorption** | Orale ou injectable | Variable selon famille |
| **D — Distribution** | Circulation sanguine | Action dans le compartiment vasculaire |
| **M — Métabolisation** | Variable | Foie important pour plusieurs molécules |
| **E — Élimination** | Rénale ± hépatique | 🫘 Fonction rénale essentielle pour plusieurs AOD/HBPM |
| **R — Réponse** | Anticoagulation | ⚠️ Surveiller surtout le saignement |

### 💉 Héparines

L’HNF IV agit rapidement.

Les HBPM sont administrées principalement par voie SC et leur effet est plus prévisible.

👉 Leur élimination fait intervenir notamment le **rein**, particulièrement pour les HBPM.

### 💊 AVK

Les AVK ont une action plus lente et une durée variable.

La warfarine possède une demi-vie relativement longue, environ **35 à 45 h**.

👉 Leur effet est influencé par :

- les interactions médicamenteuses ;
- l’alimentation ;
- la fonction hépatique ;
- l’observance.

### 💊 AOD

Les AOD ont une action relativement rapide mais une demi-vie plus courte que les AVK.

➡️ **Un oubli de prise peut rapidement diminuer la protection anticoagulante.**

🚫 **Ne jamais doubler automatiquement la prise suivante après un oubli.**

La conduite dépend de l’AOD et du moment de l’oubli.

## 💉 Administration et conservation

### ✅ Sécurité = 5 B

**Bon·ne patient·e + bon médicament + bonne dose + bonne voie + bon moment**

➕ **bonne traçabilité**

➕ **bonne surveillance**

| Classe | 💉 Administration | 🧊 Conservation |
|---|---|---|
| **HNF** | 💉 IV continue ou selon indication | Selon RCP de la spécialité |
| **HBPM** | 💉 SC, généralement abdomen | Température selon RCP ; seringue dans emballage d’origine |
| **AVK** | 💊 Orale, horaire régulier | Ex. Coumadine® : ≤ **30 °C**, emballage d’origine |
| **AOD** | 💊 Oral, 1 ou 2 prises/j selon molécule/prescription | Selon RCP |
| **Dabigatran** | 💊 Gélule | ⚠️ Conservation dans conditionnement d’origine selon spécialité |



### 💉 Injection SC d’HBPM : réflexes

- injecter selon prescription dans le **tissu sous-cutané** ;
- alterner les sites 🔄 ;
- surveiller ecchymoses et hématomes ;
- ne pas masser vigoureusement après l’injection ;
- vérifier la seringue, la concentration et la dose prescrite.

⚠️ Les seringues préremplies existent à différentes concentrations.

**UI / mg / volume → vigilance maximale.**

### 💊 AVK : administration

👉 Prise quotidienne à heure régulière selon prescription.

La dose est adaptée selon l’**INR**.

⚠️ **L’infirmier·ère ne modifie pas seul·e la posologie.**

## 🧪 Surveillance biologique : le tableau indispensable

| 💊 Traitement | 🧪 Surveillance spécifique | 🧠 À retenir |
|---|---|---|
| **HNF curative** | **TCA ou activité anti-Xa** | Surveillance rapprochée |
| **HBPM** | Pas d’anti-Xa systématique | Possible dans situations particulières |
| **Héparines** | 🩸 Plaquettes | Rechercher une TIH |
| **AVK** | **INR** | Indispensable |
| **AOD** | ❌ Pas d’INR pour adapter la dose | Fonction rénale/hépatique + Hb |
| Tous | Hb, clinique, fonction rénale selon contexte | Rechercher saignement |

Pour l’HNF curative IV, le RCP prévoit une surveillance biologique au minimum quotidienne, notamment par **TCA ou anti-Xa**, avec contrôles après début ou modification de dose.

### 🩸 INR = réservé aux AVK

L’**INR** mesure l’intensité de l’anticoagulation sous AVK.

🎯 La cible dépend de l’indication.

👉 Souvent autour de **2–3** dans de nombreuses indications, mais certaines situations nécessitent une autre cible.

🚫 **INR trop bas → risque thrombotique**

🚨 **INR trop élevé → risque hémorragique**

### 💊 AOD : pas d’INR de routine

Les AOD sont prescrits à doses déterminées selon :

- indication ;
- âge ;
- poids selon molécule ;
- fonction rénale ;
- interactions.

Avant et pendant le traitement, il faut notamment surveiller :

🫘 fonction rénale + 🫀 fonction hépatique + 🩸 hémoglobine.

## ⚠️ Risques, effets indésirables et situations à surveiller

| 💊 Classe / situation | 😵 Risque | 🔎 Signes / contexte | 👩‍⚕️ Réflexe |
|---|---|---|---|
| **Tous anticoagulants** | 🚨 Hémorragie | Saignement visible ou occulte | Évaluer + alerter |
| **Héparine** | Hématome | Point d’injection | Alterner sites + surveiller |
| **Héparine** | 🚨 **TIH** | ↓ plaquettes ± thrombose | Plaquettes + alerte immédiate |
| **AVK** | Sur-anticoagulation | INR élevé | Recherche saignement + alerte |
| **AVK + interactions** | Variation INR | Nouveau médicament/alimentation | Surveillance renforcée |
| **AOD + insuffisance rénale** | Accumulation | DFG diminué | Vérifier fonction rénale |
| Anticoagulant + AINS | 🚨 Hémorragie | Digestif notamment | Signaler association |
| Anticoagulant + antiagrégant | ↑ risque hémorragique | Ecchymoses/saignement | Surveillance renforcée |

Les AINS, antiagrégants et autres médicaments agissant sur l’hémostase peuvent augmenter le risque hémorragique associé aux héparines.

## 🚨 Reconnaître une hémorragie

### 🔴 Saignement visible

- épistaxis persistant 👃 ;
- gingivorragies ;
- hématurie 🩸 ;
- hématémèse ;
- rectorragies ;
- méléna ;
- règles anormalement abondantes ;
- hématomes étendus.

### ⚠️ Saignement caché

- pâleur ;
- fatigue brutale ;
- tachycardie ;
- hypotension ;
- malaise ;
- baisse de l’hémoglobine.

### 🧠 Hémorragie intracrânienne

🚨 Penser urgence si anticoagulant + :

- céphalée brutale ;
- déficit neurologique ;
- confusion ;
- vomissements ;
- trouble de conscience ;
- traumatisme crânien.

**Anticoagulant + chute sur la tête = vigilance maximale**

## 🩸 TIH = thrombopénie induite par l’héparine

La **TIH** est une complication immunologique rare mais grave.

Paradoxalement :

**héparine → ↓ plaquettes MAIS ↑ risque de thrombose**

🚨 Une baisse significative des plaquettes, notamment de l’ordre de **30 à 50 % de la valeur initiale**, doit faire évoquer une TIH et conduire à une évaluation immédiate.

🧠 Mémo :

**HÉPARINE + PLAQUETTES QUI CHUTENT = TIH**

➡️ Alerter immédiatement.

## 💉 Antidotes / réversion : à connaître sans les administrer seul·e

| Anticoagulant | 🛡️ Réversion spécifique / principale |
|---|---|
| **Héparine** | **Protamine** |
| **AVK** | **Vitamine K + CCP** selon gravité |
| **Dabigatran** | **Idarucizumab = Praxbind®** |
| **Anti-Xa AOD** | Prise en charge spécialisée selon molécule/situation |

La protamine neutralise l’action anticoagulante de l’héparine.

En cas d’hémorragie grave sous AVK, le RCP de la warfarine prévoit une réversion urgente associant notamment **vitamine K et concentré de complexe prothrombinique (CCP)** selon prescription spécialisée.

⚠️ **Antidote ≠ rôle autonome IDE.**

➡️ Administration selon prescription/protocole d’urgence.

## 👩‍⚕️ Surveillance et conduite infirmière

### 👀 Avant et pendant le traitement

| 👩‍⚕️ Je surveille… | 🎯 Pourquoi ? |
|---|---|
| 🩸 **Saignements** | Complication principale |
| ❤️ **TA + FC** | Rechercher retentissement hémorragique |
| 🧠 **Conscience / neurologique** | Hémorragie intracrânienne |
| 🩸 **Hb** | Détecter saignement occulte |
| 🧪 **INR** | AVK uniquement |
| 🧪 **TCA / anti-Xa** | HNF selon prescription |
| 🩸 **Plaquettes** | Rechercher TIH sous héparine |
| 🫘 **Fonction rénale** | HBPM + AOD notamment |
| 🫀 **Fonction hépatique** | AVK/AOD selon contexte |
| 💊 **Traitements associés** | Interactions + risque hémorragique |
| 🚽 Urines/selles | Rechercher sang |
| 💉 Sites d’injection | Hématomes sous HBPM |

## 🚨 Si hémorragie ou surdosage suspecté

### 1️⃣ SÉCURISER

- installer la personne ;
- évaluer conscience, respiration, circulation ;
- prévenir les chutes ;
- rechercher le siège du saignement.

### 2️⃣ ÉVALUER

Rechercher :

- ❤️ TA / FC ;
- 🫁 FR / SpO₂ selon contexte ;
- 🧠 état neurologique ;
- dernière prise/injection ;
- médicament exact ;
- dose ;
- traitements associés ;
- traumatisme récent ;
- pertes sanguines visibles.

### 3️⃣ ALERTER

🚨 Alerte médicale immédiate si :

- hémorragie importante ;
- hypotension/malaise ;
- hématémèse ou méléna ;
- déficit neurologique ;
- traumatisme crânien ;
- chute importante des plaquettes sous héparine ;
- surdosage important.

➡️ **SAMU-Centre 15** si urgence vitale.

### 4️⃣ AGIR

👩‍⚕️ **Rôle propre :**

- sécuriser ;
- surveiller ;
- quantifier les pertes si possible ;
- rechercher les signes de choc ;
- transmettre rapidement.

📋 **Prescription/protocole :**

- bilan biologique ;
- arrêt/reprise thérapeutique ;
- antidote/réversion ;
- remplissage/transfusion ;
- traitement spécifique.

⚠️ L’infirmier·ère **ne décide pas seul·e de suspendre durablement ou modifier un anticoagulant**, hors conduite prévue par un protocole d’urgence.

### 5️⃣ TRACER + TRANSMETTRE

🗣️ **SAED**

- **S** = Situation
- **A** = Antécédents
- **É** = Évaluation
- **D** = Demande

## 🩺 Mini-situation clinique + mémo

👵 Mme M., 79 ans, est traitée par **apixaban** pour fibrillation atriale.

Elle chute dans sa chambre et se cogne fortement la tête.

Elle dit :

« Ça va, je n’ai pas de sang. »

### ❓ Raisonnement

👉 L’absence de saignement visible **n’exclut pas une hémorragie interne**.

**Anticoagulant + traumatisme crânien = risque d’hémorragie intracrânienne**

👩‍⚕️ Réflexe :

**sécuriser → évaluation neurologique + constantes → identifier anticoagulant/dernière prise → alerter rapidement → surveillance → prise en charge prescrite → tracer/transmettre**

## 🧠 Mémo express

### 🩸 H.A.V.O.D.

- **H** = 💉 **Héparines** → antithrombine
- **A** = 🩸 **AVK** → INR
- **V** = 🌿 **Vitamine K bloquée** par AVK
- **O** = 💊 anticoagulants **Oraux directs**
- **D** = 🚨 **Danger = hémorragie**

### 👩‍⚕️ S.A.N.G.

Que surveiller ?

- **S** = 🩸 **Saignements**
- **A** = ❤️ **Artériel : TA/FC**
- **N** = 🧠 **Neurologique**
- **G** = 🧪 **Globules/Hb + coagulation adaptée**

### 🚨 Les 4 associations à mémoriser

**AVK = INR**

**HNF = TCA / anti-Xa**

**HÉPARINE + PLAQUETTES ↓ = TIH**

**TOUT ANTICOAGULANT + SAIGNEMENT = HÉMORRAGIE jusqu’à preuve du contraire**

## ✅ L’essentiel à retenir

| 💊 Classe | 🧠 Mécanisme | 🧪 Surveillance clé | ⚠️ Risque |
|---|---|---|---|
| **HNF** | Antithrombine → ↓ IIa/Xa | TCA/anti-Xa + plaquettes | 🚨 Hémorragie + TIH |
| **HBPM** | Antithrombine → surtout ↓ Xa | Plaquettes + rein ; anti-Xa si indication | 🚨 Hémorragie + TIH |
| **AVK** | ↓ facteurs II, VII, IX, X | **INR** | 🚨 Hémorragie |
| **AOD anti-Xa** | ↓ facteur Xa | Rein + Hb + clinique | 🚨 Hémorragie |
| **Dabigatran** | ↓ thrombine IIa | Rein + Hb + clinique | 🚨 Hémorragie |

✅ **AVK = INR**

✅ **AOD ≠ surveillance par INR**

✅ **HÉPARINE = PLAQUETTES → penser TIH**

✅ **HBPM/AOD = penser REIN**

✅ **ANTICOAGULANT = penser SAIGNEMENT**

✅ **Toujours relier : mécanisme → risque → signes → surveillance**
