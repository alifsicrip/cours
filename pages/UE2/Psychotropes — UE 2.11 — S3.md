# 🧠 Psychotropes — UE 2.11 — S3

## 🌿 Carte d’identité et grandes familles

Les **psychotropes** sont des médicaments qui agissent sur le **système nerveux central** et modifient l’activité psychique : humeur, anxiété, sommeil, pensée, comportement ou perception.

👉 Ils ne forment pas une seule famille : **chaque classe agit sur des neurotransmetteurs différents**.

| 💊 Classe | Exemple | 🎯 Action principale | 💉 Voie principale |
|---|---|---|---|
| **Antidépresseurs ISRS** | Escitalopram, sertraline | ↑ disponibilité de la sérotonine | 💊 Orale |
| **Antidépresseurs IRSNa** | Venlafaxine, duloxétine | ↑ sérotonine + noradrénaline | 💊 Orale |
| **Anxiolytiques benzodiazépines** | Lorazépam, oxazépam | Renforcent l’effet inhibiteur du GABA | 💊 Orale principalement |
| **Hypnotiques apparentés** | Zopiclone, zolpidem | Favorisent le sommeil via le GABA | 💊 Orale |
| **Antipsychotiques** | Risperidone, olanzapine, aripiprazole | Modulent principalement dopamine ± sérotonine | 💊 Orale / 💉 IM |
| **Thymorégulateurs** | Lithium = Téralithe® | Stabilise l’humeur | 💊 Orale |

🎯 Objectif commun :

**agir sur les neurotransmetteurs → réduire les symptômes → améliorer le fonctionnement et prévenir les rechutes**

⚠️ Un psychotrope peut agir sur plusieurs récepteurs : cela explique **l’effet thérapeutique ET les effets indésirables**.

## 🧠 Pharmacodynamie : ce que le médicament fait à l’organisme

💡 **Pharmacodynamie = comment le médicament agit sur le cerveau.**

Imagine les neurones comme une **forêt qui communique par des messagers chimiques** 🌳📨.

Ces messagers sont les **neurotransmetteurs**.

Les principaux à retenir :

- 😊 **sérotonine** → humeur, anxiété, sommeil ;
- ⚡ **noradrénaline** → vigilance, énergie ;
- 🎯 **dopamine** → motivation, mouvement, récompense, perceptions ;
- 🛑 **GABA** → principal frein du cerveau.

### 😊 1. Antidépresseurs → SÉROTONINE ± NORADRÉNALINE

#### 💊 ISRS

Exemple : **escitalopram**.

Normalement, la sérotonine libérée entre deux neurones est en partie **recaptée**.

Les ISRS bloquent cette recapture.

➡️ La sérotonine reste disponible plus longtemps.

**ISRS → ↓ recapture de sérotonine → ↑ sérotonine synaptique → amélioration progressive de l’humeur/anxiété**

⚠️ L’effet thérapeutique n’est **pas immédiat**.

👉 L’amélioration est évaluée sur plusieurs semaines ; la HAS situe classiquement l’évaluation de l’efficacité d’un traitement antidépresseur autour de **4 à 8 semaines**.

#### ⚡ IRSNa

Exemple : **venlafaxine**.

Ils freinent la recapture de :

**sérotonine + noradrénaline**

➡️ ↑ disponibilité de ces neurotransmetteurs.

⚠️ Plusieurs médicaments sérotoninergiques associés peuvent favoriser un **syndrome sérotoninergique**, potentiellement grave.

### 🛑 2. Benzodiazépines → GABA

Exemple : **lorazépam**.

Le **GABA est le frein naturel du cerveau**.

Les benzodiazépines renforcent son action.

**Benzodiazépine → ↑ effet GABA → ↓ excitabilité neuronale**

➡️ anxiolyse 😌

➡️ sédation 😴

➡️ effet anticonvulsivant pour certaines molécules

➡️ relâchement musculaire variable.

🧠 Image mentale :

**Le cerveau accélère 🚗 → le GABA appuie sur le frein 🛑 → la benzodiazépine renforce le frein.**

⚠️ Plus le traitement se prolonge, plus augmentent notamment les risques de **dépendance, somnolence, troubles de mémoire et chutes**. La prescription dans l’anxiété ou l’insomnie doit donc rester limitée dans le temps.

### 🌙 3. Hypnotiques → SOMMEIL

Les hypnotiques apparentés aux benzodiazépines, comme le **zolpidem** ou la **zopiclone**, agissent également sur le système GABAergique.

➡️ ↓ éveil.

➡️ favorisent l’endormissement.

⚠️ Ils ne traitent pas nécessairement **la cause de l’insomnie**.

🚨 Risques :

**somnolence + chute + troubles mnésiques + dépendance**

La HAS recommande leur utilisation pour les troubles sévères du sommeil **sur une durée courte**.

### 🎯 4. Antipsychotiques → DOPAMINE ± SÉROTONINE

Exemples :

- **rispéridone** ;
- **olanzapine** ;
- **aripiprazole**.

Ils modulent principalement la neurotransmission **dopaminergique**, souvent associée à une action sérotoninergique selon la molécule.

➡️ ↓ hallucinations.

➡️ ↓ idées délirantes.

➡️ ↓ agitation liée à certains troubles psychotiques.

Mais la dopamine intervient également dans le **mouvement**.

Donc :

**blocage dopaminergique → bénéfice psychiatrique MAIS risque de symptômes extrapyramidaux**

⚠️ Certains antipsychotiques exposent aussi à :

- prise de poids ;
- hyperglycémie ;
- dyslipidémie ;
- hypotension ;
- sédation ;
- troubles du rythme selon la molécule.

La surveillance régulière des traitements neuroleptiques est un point majeur de sécurité identifié par la HAS.

### ⚖️ 5. Lithium → STABILISER L’HUMEUR

Exemple : **Téralithe®**.

Le lithium est un **thymorégulateur**.

Il stabilise l’activité neuronale par plusieurs mécanismes intracellulaires complexes.

🎯 Il est notamment utilisé pour :

- traiter certains épisodes maniaques ;
- prévenir les récidives maniaques ou dépressives du trouble bipolaire.

🧠 Image mentale :

**Humeur = bateau ⛵**

Manie ⬆️🌊 — Dépression ⬇️🌊

➡️ **Lithium = lest qui aide à stabiliser le bateau.**

🚨 Particularité essentielle :

**marge thérapeutique étroite → concentration efficace proche de la concentration toxique**

👉 **LITHIUM = LITHÉMIE + REIN + HYDRATATION**

## 🧪 Pharmacocinétique + LADMER

💡 **Pharmacocinétique = ce que l’organisme fait au médicament.**

🧠 **LADMER = le voyage du psychotrope.**

| Étape | 💊 Ce qui se passe | 👩‍⚕️ À retenir |
|---|---|---|
| **L — Libération** | Libération du principe actif | ⚠️ Attention aux formes LP |
| **A — Absorption** | Souvent digestive | Majoritairement voie orale |
| **D — Distribution** | Passage sanguin puis cérébral | Action sur le SNC |
| **M — Métabolisation** | Souvent hépatique | Interactions possibles |
| **E — Élimination** | Rein et/ou foie selon molécule | Fonction d’organe importante |
| **R — Réponse** | Effet psychique recherché | Efficacité + effets indésirables |

### 💊 Antidépresseurs / antipsychotiques / benzodiazépines

Beaucoup sont :

**💊 absorbés par l’intestin → 🩸 circulation → 🫀 métabolisés par le foie → élimination**

👉 Une atteinte hépatique, rénale, l’âge ou des interactions peuvent modifier l’exposition selon la molécule.

### ⚖️ Lithium = exception à retenir

Le lithium :

- est absorbé par voie digestive ;
- n’est pas métabolisé comme beaucoup d’autres psychotropes ;
- est éliminé principalement par les **reins**.

Donc :

**déshydratation / altération rénale → ↓ élimination → ↑ lithium sanguin → INTOXICATION**

🚨 **LITHIUM = TOUJOURS PENSER REIN + EAU + LITHÉMIE**

## 💊 Administration et conservation

### ✅ Sécurité = 5 B

**Bon·ne patient·e + bon médicament + bonne dose + bonne voie + bon moment**

➕ **traçabilité + surveillance clinique**

| Classe | 💉 Administration | 🧊 Conservation |
|---|---|---|
| **Antidépresseurs** | 💊 Orale le plus souvent | Température selon RCP, généralement ambiante |
| **Benzodiazépines** | 💊 Orale ; certaines formes 💉 selon indication | Selon RCP |
| **Hypnotiques** | 💊 Orale, généralement au coucher | Selon RCP |
| **Antipsychotiques oraux** | 💊 Comprimé, solution ou orodispersible selon spécialité | Selon RCP |
| **Antipsychotiques injectables immédiats** | 💉 IM selon prescription/situation | Variable selon spécialité |
| **Antipsychotiques retard / dépôt** | 💉 IM à intervalles programmés | ⚠️ Conservation propre au produit |
| **Lithium** | 💊 Oral ; formes immédiates ou LP | Selon RCP |

⚠️ **Toujours vérifier le RCP de la spécialité exacte**, notamment pour :

- conservation ;
- dilution éventuelle ;
- voie IM ;
- forme LP ;
- antipsychotiques injectables retard.

🚫 **Ne pas écraser une forme LP sans vérification.**

🚫 Ne pas interrompre brutalement un psychotrope sans décision médicale, particulièrement les benzodiazépines : un arrêt trop rapide après utilisation prolongée peut provoquer un **syndrome de sevrage**.

## ⚠️ Risques, effets indésirables et situations à surveiller

| 💊 Classe / situation | 😵 Risque | 🔎 Signes à repérer | 👩‍⚕️ Réflexe |
|---|---|---|---|
| **Antidépresseur** | Nausées, troubles sexuels, agitation, sommeil perturbé selon molécule | Tolérance, comportement | Évaluer + transmettre |
| Début d’antidépresseur | ⚠️ Risque suicidaire à surveiller selon contexte | Idées suicidaires, agitation, changement brutal | 🚨 Évaluer et alerter |
| Plusieurs sérotoninergiques | 🚨 **Syndrome sérotoninergique** | Agitation, hyperthermie, tachycardie, hyperréflexie, diarrhée | **Urgence médicale** |
| **Benzodiazépines / hypnotiques** | 😴 Somnolence | Vigilance diminuée | Prévention des chutes |
| Benzodiazépines prolongées | Dépendance / sevrage | Anxiété, agitation, tremblements selon contexte | Pas d’arrêt brutal |
| Benzodiazépines + dépresseurs SNC | 🚨 Dépression respiratoire/sédation majorée | Bradypnée, somnolence, coma | Surveillance + urgence |
| **Antipsychotiques** | Symptômes extrapyramidaux | Tremblement, rigidité, akathisie, dystonie | Évaluer + alerter |
| Antipsychotiques | Métabolique | Poids ↑, glycémie ↑, lipides ↑ | Poids + bilan prescrit |
| Antipsychotiques | Cardiovasculaire | Hypotension, malaise, QT selon molécule | TA + ECG si prescrit |
| Antipsychotique + hyperthermie | 🚨 **Syndrome malin des neuroleptiques** | Fièvre + rigidité + confusion + dysautonomie | **URGENCE** |
| **Clozapine** | 🚨 Neutropénie/agranulocytose | Fièvre, angine, infection | NFS/PNN selon protocole + alerte |
| **Lithium** | 🚨 Intoxication | Tremblements importants, diarrhées, vomissements, confusion, troubles neurologiques | Lithémie + urgence |

### 🚨 Syndrome malin des neuroleptiques = S.M.N.

Rare mais **potentiellement mortel**.

À reconnaître :

🌡️ **hyperthermie**

➕ 🪨 **rigidité musculaire**

➕ 🧠 **altération de la conscience**

➕ ❤️ **instabilité végétative** : tachycardie, variation de TA, hypersudation, troubles du rythme.

Des CPK élevées, une rhabdomyolyse et une insuffisance rénale aiguë peuvent également apparaître.

🧠 Mémo :

**Neuroleptique + FIÈVRE + RIGIDITÉ + CONFUSION = SMN jusqu’à élimination**

➡️ **URGENCE MÉDICALE**

### 🔥 Syndrome sérotoninergique

Trop de stimulation sérotoninergique peut provoquer :

- 😵 agitation / confusion ;
- 🌡️ hyperthermie ;
- ❤️ tachycardie ;
- 💦 hypersudation ;
- 🦵 hyperréflexie / troubles neuromusculaires ;
- 🤢 nausées, vomissements, diarrhées.

➡️ **Sérotonine + signes neurologiques + végétatifs = URGENCE**

Le risque augmente notamment lors de certaines **associations de médicaments sérotoninergiques**.

### ⚖️ Intoxication au lithium

⚠️ Penser immédiatement au contexte :

- 💧 déshydratation ;
- 🤮 diarrhées/vomissements ;
- 🫘 altération rénale ;
- 💊 interaction médicamenteuse ;
- modification importante des apports hydrosodés.

Signes possibles :

🫨 tremblements importants → 🤢 troubles digestifs → 😵 confusion / troubles de l’équilibre → atteinte neurologique sévère.

➡️ **Suspicion d’intoxication = lithémie + évaluation médicale urgente.**

### 🩸 Clozapine = penser PNN

La **clozapine** peut provoquer une **agranulocytose**.

👉 Sa prescription nécessite une surveillance spécifique des **polynucléaires neutrophiles (PNN)**.

Le RCP français 2026 prévoit une surveillance régulière, notamment **hebdomadaire pendant les 18 premières semaines**, puis espacée selon le calendrier réglementaire.

🧠 **CLOZAPINE + FIÈVRE/ANGINE = penser NEUTROPÉNIE**

## 👩‍⚕️ Surveillance et conduite infirmière

### 👀 Avant et pendant le traitement

| 👩‍⚕️ Je surveille… | 🎯 Pourquoi ? |
|---|---|
| 🧠 **État psychique** | Efficacité, agitation, délire, humeur |
| 💭 **Idées suicidaires** | Sécurité, notamment selon contexte dépressif |
| 😴 **Vigilance** | Sédation, benzodiazépines, antipsychotiques |
| 🚶 **Marche / chutes** | Sédation + hypotension |
| ❤️ **TA / FC** | Hypotension, effets végétatifs |
| ⚖️ **Poids / IMC** | Risque métabolique antipsychotique |
| 🩸 **Glycémie / bilan lipidique** | Risque métabolique selon antipsychotique |
| 🦵 **Motricité** | Syndrome extrapyramidal |
| 🌡️ **Température** | Dépister SMN / infection |
| 🫘 **Fonction rénale** | Essentielle avec lithium |
| ⚖️ **Lithémie** | Éviter sous/surdosage du lithium |
| 🩸 **NFS / PNN** | Clozapine |
| 💊 **Observance / interactions** | Prévenir rechute et toxicité |

### 🚨 Si complication suspectée

**1️⃣ SÉCURISER**

- rester auprès de la personne selon gravité ;
- prévenir chute, fugue ou mise en danger ;
- évaluer conscience, respiration et circulation ;
- sécuriser l’environnement.

**2️⃣ ÉVALUER**

Rechercher :

🧠 état de conscience + comportement + 🌡️ température + ❤️ TA/FC + 🫁 FR/SpO₂ selon situation + traitement + dernière prise + modification récente + autres substances/médicaments.

**3️⃣ ALERTER**

🚨 Alerte médicale urgente si :

- syndrome malin des neuroleptiques suspecté ;
- syndrome sérotoninergique suspecté ;
- intoxication au lithium ;
- coma ou dépression respiratoire ;
- convulsions ;
- intention suicidaire imminente ;
- surdosage important ;
- fièvre/infection sous clozapine selon contexte.

➡️ **SAMU-Centre 15** devant une urgence vitale.

**4️⃣ AGIR**

- 👩‍⚕️ **Rôle propre** : sécuriser, observer, évaluer, surveiller, prévenir les chutes, maintenir une relation thérapeutique, transmettre.
- 📋 **Prescription/protocole** : bilans biologiques, ECG, traitements correcteurs et adaptations thérapeutiques.

⚠️ L’infirmier·ère **ne décide pas seul·e de modifier ou d’arrêter durablement le traitement**.

**5️⃣ TRACER + TRANSMETTRE**

🗣️ **SAED = Situation → Antécédents → Évaluation → Demande**

## 🩺 Mini-situation clinique + mémo

👤 M. L. est hospitalisé pour un épisode psychotique.

Il reçoit un **antipsychotique** depuis quelques jours.

Ce matin :

🌡️ température 39,5 °C

🪨 rigidité musculaire

😵 confusion

💦 sueurs importantes

❤️ tachycardie.

### ❓ Raisonnement

👉 Suspecter immédiatement un :

🚨 **SYNDROME MALIN DES NEUROLEPTIQUES**

Pourquoi ?

**Antipsychotique + hyperthermie + rigidité + altération neurologique + dysautonomie = tableau d’alerte**

### 👩‍⚕️ Réflexe

**Sécuriser → constantes → conscience → alerter immédiatement → surveillance rapprochée → bilans/prise en charge selon prescription → tracer/transmettre**

## 🧠 Mémo express

### 🌳 S.A.G.E. = sur quoi agissent les psychotropes ?

- **S** = 😊 **Sérotonine** → antidépresseurs
- **A** = ⚡ **Adrénaline/noradrénaline** → certains antidépresseurs
- **G** = 🛑 **GABA** → benzodiazépines/hypnotiques
- **E** = 🎯 **Équilibre dopamine/humeur** → antipsychotiques + thymorégulateurs

### 👩‍⚕️ P.S.Y.C.H.O. = que surveiller ?

- **P** = ⚖️ Poids / paramètres métaboliques
- **S** = 🌡️ Syndrome malin / sérotoninergique
- **Y** = 👀 Yeux ouverts = vigilance / conscience
- **C** = ❤️ Cardiaque : TA, FC, ECG si prescrit
- **H** = 🙂 Humeur / comportement / idées suicidaires
- **O** = 💊 Observance + effets indésirables

### 🚨 Les 4 associations à mémoriser

**Antipsychotique + FIÈVRE/RIGIDITÉ = SMN**

**Antidépresseurs sérotoninergiques + AGITATION/HYPERTHERMIE = syndrome sérotoninergique**

**Lithium + DÉSHYDRATATION/TREMBLEMENTS = intoxication**

**Benzodiazépine + SOMNOLENCE/BRADYPNÉE = sur-sédation**
