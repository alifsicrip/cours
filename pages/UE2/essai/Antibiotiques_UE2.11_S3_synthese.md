# 💊 Antibiotiques — UE 2.11 S3
> ### 🧠 Fiche de révision synthétique — pharmacologie & rôle IDE

---

## 🎯 1. L'essentiel en 30 secondes

**Antibiotique = médicament actif contre certaines bactéries.**  
➡️ Il traite une **infection bactérienne**, pas une infection virale.

### 🧭 Choisir un antibiotique
Le choix dépend notamment de :

| 🔎 À vérifier | 🎯 Pourquoi ? |
|---|---|
| 🦠 Foyer / germe suspecté | Cibler l'infection |
| 🧪 Antibiogramme | Adapter au germe identifié |
| 🚨 Gravité | Adapter l'urgence et le traitement |
| 👤 Terrain | Âge, poids, allergies, comorbidités… |
| 🚽 Fonction rénale | Éviter accumulation/toxicité |
| 🏭 Fonction hépatique | Selon la molécule |
| 🛡️ Résistances | Préserver l'efficacité future |

### 🧠 Logique générale
**Infection suspectée → prélèvements si indiqués → antibiothérapie adaptée → surveillance → résultats microbiologiques → réévaluation**

➡️ **Poursuivre • adapter • réduire le spectre • arrêter**

---

## 🧪 2. Deux grands types d'action

| ⚔️ Type | Action | À retenir |
|---|---|---|
| 🗡️ **Bactéricide** | Tue les bactéries | ↓ population bactérienne |
| 🛑 **Bactériostatique** | Bloque/ralentit leur multiplication | Les défenses immunitaires participent à l'élimination |

> ⚠️ **Bactéricide ≠ forcément meilleur**  
> **Bactériostatique ≠ inefficace** : le résultat dépend de la molécule, de sa concentration, du germe et du site infectieux.

---

## 📖 3. Définitions indispensables

| 📚 Terme | 🧠 Définition express |
|---|---|
| **Antibiotique** | Substance qui inhibe ou détruit certaines bactéries |
| **Antibiothérapie** | Traitement par un ou plusieurs antibiotiques |
| **Probabiliste** | Débutée avant identification définitive du germe, selon le contexte clinique |
| **Documentée** | Adaptée après identification microbiologique et étude de sensibilité |
| **Antibiogramme** | Teste la sensibilité d'une bactérie aux antibiotiques |
| **Spectre antibactérien** | Ensemble des bactéries sensibles à un antibiotique |
| **CMI** | Plus faible concentration empêchant la croissance visible d'une bactérie |
| **Antibiorésistance** | Capacité d'une bactérie à résister à un antibiotique |
| **Pression de sélection** | L'antibiotique élimine préférentiellement les bactéries sensibles, favorisant la survie relative des résistantes |

### 🧪 Antibiogramme
Résultats possibles :
- 🟢 **Sensible**
- 🟠 **Sensible à exposition augmentée**
- 🔴 **Résistant**

### 🎯 Spectre
| Spectre | Intérêt / risque |
|---|---|
| 🎯 **Étroit** | Ciblé → limite l'impact écologique |
| 🌐 **Large** | Couvre davantage d'espèces → utile dans certaines situations mais pression de sélection plus importante |

> 💡 **Image mentale :** un antibiotique mal utilisé agit comme un filtre : les bactéries sensibles disparaissent davantage, tandis que les résistantes peuvent persister et se multiplier.

---

## ⭐ 4. Objectifs du traitement

### 🩺 Objectifs thérapeutiques
- Éliminer ou contrôler la bactérie
- ↓ symptômes
- Contrôler le foyer infectieux
- Prévenir les complications
- Limiter la diffusion de l'infection lorsque pertinent

### 🛡️ Bon usage
**Bonne indication + bonne molécule + bonne dose + bonne voie + bon rythme + bonne durée + bonne réévaluation**

> ⭐ **Formule à retenir :**  
> **Efficacité = médicament adapté + exposition suffisante + bactérie sensible + surveillance adaptée**

# ⚗️ 6. Pharmacocinétique : LADME

> 🧠 **PK = ce que l'organisme fait au médicament.**  
> **PD = ce que l'antibiotique fait à la bactérie.**

### 🚦 LADME
**L**ibération → **A**bsorption → **D**istribution → **M**étabolisme → **E**limination

| Étape | 🧠 À comprendre | 👩‍⚕️ Vigilance |
|---|---|---|
| 💊 **Libération** | Le principe actif est mis à disposition depuis sa forme pharmaceutique | Ne pas écraser/ouvrir sans vérifier |
| 🚪 **Absorption** | Passage vers la circulation générale | Alimentation, vomissements, diarrhée, interactions |
| 🚚 **Distribution** | Passage du sang vers les tissus | Atteindre le foyer infectieux |
| 🏭 **Métabolisme** | Transformation par l'organisme | Foie et interactions selon molécule |
| 🚽 **Élimination** | Évacuation du médicament | Rein, foie/bile ou voie mixte |

### 💊 Libération : formes
| Forme | Particularité |
|---|---|
| 💊 Comprimé | Libération puis absorption digestive |
| 💊 Gélule | Libération digestive |
| 🥄 Suspension | Homogénéiser selon le produit |
| 💉 IV | Introduction directe dans la circulation |

### 🚪 Absorption : pièges
- 🍽️ Alimentation → effet variable selon la molécule
- 🤮 Vomissements → dose absorbée potentiellement diminuée
- 💩 Diarrhée → absorption potentiellement perturbée
- 💊 Médicaments associés → interactions possibles
- 🥛 Calcium / 💊 fer → interactions avec certaines molécules

> 💡 **Exemple : doxycycline + certains cations → complexes → ↓ absorption.**

### 🚚 Distribution
Le médicament doit atteindre le foyer à une **concentration suffisante**.

Sites particuliers à considérer : 🧠 SNC • 🦴 os • 🫁 poumon • prostate • urines • abcès.

### 🚽 Élimination
| Voie | Concernés |
|---|---|
| 🚽 Rénale | Nombreux antibiotiques |
| 🏭 Hépatobiliaire | Certaines molécules |
| 🔄 Mixte | Certaines molécules |

**Insuffisance rénale → ↓ élimination → accumulation possible → ↑ toxicité → adaptation posologique parfois nécessaire.**

🔎 Surveillance selon contexte : **créatininémie • fonction rénale estimée • diurèse • évolution biologique**

# 🎯 8. Où agit l'antibiotique ?

| 🎯 Cible bactérienne | 💊 Familles | ⚗️ Conséquence |
|---|---|---|
| 🧱 **Paroi** | Bêta-lactamines, glycopeptides | Fragilisation de la paroi |
| 🏭 **Ribosome** | Macrolides, cyclines, aminosides | Blocage de la synthèse protéique |
| 🧬 **ADN** | Fluoroquinolones | Perturbation de la réplication |
| ⚗️ **Folates** | Cotrimoxazole | Blocage du métabolisme bactérien |

### 🏭 Métaphore de l'usine
- 🧱 **Paroi** = murs
- 🏭 **Ribosome** = machines de production
- 🧬 **ADN** = plans de fabrication
- ⚗️ **Folates** = matières premières

➡️ L'antibiotique **sabote une fonction précise**.

# ⚠️ 10. Effets indésirables à connaître

| ⚠️ EIM | 💊 Exemples / familles | 👀 Vigilance |
|---|---|---|
| 💩 Digestifs | Nausées, diarrhée, vomissements | Selon molécule |
| 🧴 Allergiques | Éruption, urticaire, anaphylaxie | Bêta-lactamines notamment |
| 🚽 Néphrotoxiques | Altération rénale | Aminosides, vancomycine |
| 👂 Ototoxiques | Atteinte auditive/vestibulaire | Aminosides |
| ❤️ Cardiaques | Allongement du QT | Certains macrolides, fluoroquinolones |
| 🦵 Tendineux | Tendinopathie, rupture | Fluoroquinolones |
| 🧠 Neurologiques | Confusion, neuropathie, convulsions selon contexte | Plusieurs molécules |
| ☀️ Cutanés | Photosensibilisation | Cyclines notamment |
| 🏭 Hépatiques | Cytolyse, cholestase | Variable |
| 🦠 Microbiote | Candidose, diarrhée, *C. difficile* | Antibiothérapie en général |

# 🚨 11. Situations d'alerte

| 🚨 Situation | Signes possibles | ⚡ Réflexe |
|---|---|---|
| **Anaphylaxie** | Dyspnée, œdème, hypotension, malaise | Arrêt de l'administration en cours + urgence |
| **Sepsis / aggravation** | Hypotension, tachycardie, polypnée, confusion | Alerte médicale urgente |
| **Réaction cutanée grave** | Bulles, décollement, atteinte muqueuse | Urgence médicale |
| **Toxicité rénale** | Oligurie, créatinine en hausse | Alerte + surveillance |
| **Toxicité neurologique** | Confusion, convulsion | Alerte immédiate |
| **Diarrhée sévère** | Diarrhée importante, fièvre, douleur | Rechercher une complication |
| **Tendinopathie sous fluoroquinolone** | Douleur/gonflement tendineux | Alerte rapide |

### ☠️ Surdosage
Il n'existe **pas d'antidote universel**.

➡️ Identifier **molécule + dose + heure** → évaluer les signes → alerter le médecin → surveillance adaptée → avis toxicologique selon situation.

---

# ⛔ 12. Contre-indications & terrain à risque

> ⚠️ **Pas de contre-indication universelle : chaque antibiotique a ses propres contre-indications.**

| Situation | Pourquoi ? |
|---|---|
| 🧴 Hypersensibilité connue | Risque de réaction allergique grave |
| 🚽 Insuffisance rénale | Accumulation de certaines molécules |
| 🏭 Insuffisance hépatique | Risque selon le métabolisme |
| 🤰 Grossesse | Évaluation spécifique selon molécule |
| 🍼 Allaitement | Passage possible dans le lait |
| 💊 Interactions | Toxicité ↑ ou efficacité ↓ |
| ❤️ QT long | Risque rythmique avec certaines molécules |

### ⚠️ Terrain à risque
**Personne âgée • polymédication • insuffisance rénale/hépatique • grossesse/allaitement • antécédents allergiques • troubles du rythme • déshydratation • antécédent de tendinopathie avec fluoroquinolones**

### 🧴 Réflexe allergie
Ne pas noter seulement « allergique aux antibiotiques ».

Rechercher : **molécule → réaction → gravité → délai d'apparition → date approximative**

---

# ⚖️ 13. Posologie : raisonner, ne pas réciter

> 🚨 **Il n'existe aucune posologie unique pour les antibiotiques.**

Elle dépend notamment de : **molécule • infection • gravité • germe • poids • fonction rénale/hépatique • interactions • voie • recommandations**

### 🧠 Les 7 questions
| ❓ | Réflexe |
|---|---|
| 💊 **QUOI ?** | DCI prescrite |
| ⚖️ **COMBIEN ?** | Dose unitaire |
| ⏰ **QUAND ?** | Fréquence + horaires |
| 🚪 **COMMENT ?** | Voie |
| 👤 **POUR QUI ?** | Âge, poids, terrain |
| 🚽 **QUEL REIN ?** | Fonction rénale |
| 📆 **COMBIEN DE TEMPS ?** | Durée prescrite |

👩‍⚕️ **Toujours vérifier la prescription.** Ne jamais appliquer une posologie mémorisée sans vérifier **dose + voie + fréquence + terrain**.

---

# 🧪 14. Antibiogramme & réévaluation

### 🔄 Logique
**Suspicion bactérienne → prélèvement si indiqué → probabiliste si nécessaire → culture → identification → antibiogramme → comparaison → réévaluation**

Puis :
- ✅ conserver
- 🔄 changer
- 🎯 réduire le spectre
- ⚖️ adapter la dose
- 🚪 adapter la voie
- 📆 adapter la durée
- 🛑 arrêter

### 🎯 Désescalade
Passage d'un traitement large à un traitement **plus ciblé lorsque possible**.

Objectifs : **efficacité maintenue + moins d'EIM + ↓ pression de sélection + préservation du microbiote**

> ⚠️ Les prélèvements sont réalisés avant la première dose **lorsque possible**, mais une antibiothérapie urgente ne doit pas être retardée pour un prélèvement.

# 🗣️ 15. Éducation du patient

| 💬 Message | 🧠 Pourquoi ? |
|---|---|
| 💊 Respecter la dose | Ne pas modifier seul·e |
| ⏰ Respecter les horaires | Maintenir une exposition efficace |
| 📆 Respecter la durée prescrite | Ne pas modifier sans avis professionnel |
| 🚫 Ne pas partager | Traitement adapté à une situation précise |
| 🚫 Ne pas réutiliser un reste | Une nouvelle infection nécessite une nouvelle évaluation |
| 🧴 Signaler une allergie | Prévenir une réaction grave |
| 💊 Signaler les autres traitements | Repérer les interactions |
| 🚨 Signaler un effet inhabituel | Repérer une complication rapidement |

### 🛡️ Antibiorésistance
Utiliser un antibiotique **uniquement lorsqu'il est nécessaire** permet de préserver son efficacité :
- pour le/la patient·e ;
- pour les autres ;
- pour l'avenir.

# 🧠 16. Pièges classiques de partiel

| ❌ À ne pas confondre | ✅ À retenir |
|---|---|
| Antibiotique / antiviral | Bactérie / virus |
| Infection / inflammation | Agent infectieux / réponse inflammatoire |

| EIM / allergie | Toute réaction indésirable n'est pas une allergie |

# 🎓 21. Ce qui est particulièrement attendu au partiel

### 🧠 Savoir expliquer
- Pourquoi vérifier la **fonction rénale** → élimination diminuée → accumulation/toxicité possible.
- Pourquoi respecter les **horaires** → maintenir une exposition suffisante.
- Pourquoi prélever **avant la première dose lorsque possible** → identifier le germe et réaliser l'antibiogramme.
- Pourquoi éviter un spectre **inutilement large** → pression de sélection et impact sur le microbiote.
- Pourquoi **réévaluer** → efficacité, tolérance, microbiologie, spectre, dose, voie et durée.

### 👩‍⚕️ Réflexe IDE
> **Pourquoi ? → Quoi ? → Combien ? → Comment ? → Pour qui ? → Efficace ? → Toléré ?**
