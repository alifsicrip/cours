# 🦠 Antibiotiques et anti-infectieux — UE 2.11 — S3

## 🌿 Carte d’identité et grandes familles

Les **antibiotiques antibactériens** agissent contre les bactéries en ciblant une structure ou une fonction indispensable à leur survie.

🎯 Selon la famille, ils peuvent attaquer :

- 🧱 la **paroi bactérienne** ;
- 🏭 la **fabrication des protéines** ;
- 🧬 l’**ADN bactérien**.

⚠️ Le **fluconazole** est différent : c’est un **antifongique azolé** contre les champignons, et non un antibiotique antibactérien.

### ⚠️ Correction importante de classification

Dans la classification officielle française :

- **cefazoline = C1G** ;
- **céfotaxime + ceftriaxone + ceftazidime = C3G** ;
- **cefepime = C4G**.

👉 Il n’y a donc **pas de C2G dans ta liste**.

Et « Eriapenem » correspond à **ertapénème**. La Base publique des médicaments classe bien le céfotaxime, la ceftriaxone et la ceftazidime parmi les céphalosporines de 3e génération, et le cefepime parmi celles de 4e génération.

## 🧠 Pharmacodynamie : ce que l’anti-infectieux fait au micro-organisme

Imagine la bactérie comme une **petite ville autonome** 🌆.

Pour survivre elle a besoin :

🧱 d’une muraille ;

🏭 d’usines fabriquant ses protéines ;

🧬 d’un plan de construction ADN.

Chaque famille sabote une partie différente de la ville.

# 🧱 1. β-LACTAMINES → LA PAROI

Les β-lactamines comprennent :

- pénicillines ;
- céphalosporines ;
- carbapénèmes ;
- monobactames.

Elles se fixent sur les **PLP/PBP = protéines liant les pénicillines**.

Ces enzymes construisent le **peptidoglycane**, élément majeur de la paroi bactérienne.

Donc :

**β-lactamine → inhibition PBP → paroi fragile → lyse bactérienne 💥**

➡️ effet **bactéricide**.

🧠 Mémo :

# **β-LACTAMINE = BRIQUE 🧱**

La bactérie essaie de construire son mur mais l’antibiotique vole le ciment.

### ⏱️ Effet temps-dépendant

Pour beaucoup de β-lactamines, l’efficacité dépend surtout du temps pendant lequel la concentration reste suffisamment élevée au-dessus de la **CMI**.

🧠 Mémo :

**β-lactamines = le TEMPS compte ⏱️**

➡️ Respecter les horaires d’administration est essentiel.

## 🔑 β-lactamases : les ciseaux de résistance

Certaines bactéries fabriquent des :

**β-lactamases ✂️**

Elles détruisent l’anneau β-lactame.

Pour protéger certaines pénicillines, on ajoute un inhibiteur :

### Amoxicilline + acide clavulanique

**amoxicilline = attaque la paroi**

+

**acide clavulanique = neutralise certaines β-lactamases**

🧠 Image :

💊 amoxicilline = chevalier ⚔️

🛡️ acide clavulanique = bouclier.

### Pipéracilline + tazobactam

Même principe :

**pipéracilline = β-lactamine**

+

**tazobactam = inhibiteur de β-lactamases**

👉 Utilisée notamment dans des infections sévères et à risque de bacilles Gram négatifs, dont **Pseudomonas aeruginosa** selon contexte microbiologique.

# 🧱 Les céphalosporines

## 1️⃣ C1G → Cefazoline

### Cefazoline

Utilisée notamment dans :

- certaines infections à bactéries sensibles ;
- surtout très connue en IFSI pour l’**antibioprophylaxie chirurgicale**.

🧠 Mémo :

**CEFAZOLINE = CHIRURGIE 🏥**

## 3️⃣ C3G

### Cefotaxime

C3G injectable.

👉 Utilisée dans diverses infections sévères, notamment selon contexte :

- pneumonies ;
- infections urinaires compliquées ;
- méningites ;
- bactériémies.

### Ceftriaxone

C3G injectable.

Particularité pratique :

⏳ **demi-vie longue** → administrations relativement espacées selon indication.

⚠️ Particularité importante : précautions spécifiques avec les **solutions contenant du calcium**, particulièrement chez le nouveau-né.

🧠 Mémo :

**CEFTRIAXONE = C3G longue durée ⏳**

### Ceftazidime

C3G avec activité importante sur certains **Gram négatifs**, notamment :

# **Pseudomonas aeruginosa 🦠**

🧠 Mémo :

**TAZIDIME → pense PseudomonAS**

## 4️⃣ C4G → Cefepime

Le **cefepime est une C4G**.

Large activité sur de nombreux Gram positifs et Gram négatifs, avec activité notamment sur **Pseudomonas**.

⚠️ Chez une personne avec insuffisance rénale :

**accumulation → neurotoxicité possible**

Signes :

- confusion ;
- troubles de conscience ;
- myoclonies ;
- convulsions.

🧠 Réflexe :

**CEFEPIME + CONFUSION + REIN ↓ = penser accumulation**

# 🧱 Carbapénèmes

Exemples :

- **méropénème** ;
- **imipénème** ;
- **ertapénème**.

Ce sont des β-lactamines à **très large spectre**, réservées à certaines infections sévères ou bactéries résistantes.

🌍 Image écologique :

Les carbapénèmes sont comme une **tronçonneuse très puissante** 🌳.

👉 Très utile lorsqu’elle est nécessaire.

👉 Mais l’utiliser inutilement détruit aussi une grande partie de l’écosystème bactérien et favorise la sélection de résistances.

Donc :

# **CARBAPÉNÈME = préserver autant que possible**

### Méropénème

Large spectre.

👉 Couvre notamment de nombreux bacilles Gram négatifs et **Pseudomonas** selon sensibilité.

### Imipénème

Large spectre.

⚠️ Risque neurologique, notamment **convulsions**, favorisé par certaines situations dont insuffisance rénale.

### Ertapénème

Large spectre MAIS :

🚫 pas d’activité clinique utile sur **Pseudomonas aeruginosa**.

🧠 Mémo :

**ERTApénème = Pseudomonas s’en ÉCARTE 🚪**

# 🧱 Monobactame → AZTRÉONAM

L’aztréonam est une β-lactamine particulière.

👉 Activité essentiellement sur les **bactéries Gram négatives aérobies**.

Il peut notamment être actif contre :

**Pseudomonas aeruginosa**

selon antibiogramme.

🧠 Mémo :

**AZTRÉONAM = surtout GRAM −**

# 🏭 2. AMINOSIDES → RIBOSOME 30S

### Gentamicine — Amikacine

Les aminosides pénètrent dans la bactérie et se fixent sur :

# **ribosome 30S**

Ils perturbent la lecture de l’ARN messager.

➡️ protéines anormales.

➡️ mort bactérienne.

👉 Ils sont **bactéricides**.

### ⚡ Effet concentration-dépendant

Contrairement aux β-lactamines :

**aminosides = plus le pic est adapté, plus l’effet bactéricide est important**

🧠 Mémo :

**AMINOSIDE = GROS COUP ⚡**

Ils possèdent aussi un **effet post-antibiotique** : l’activité persiste un certain temps après la diminution de la concentration.

## 🚨 Deux toxicités majeures

# 🫘 NÉPHROTOXICITÉ

et

# 👂 OTOTOXICITÉ

La toxicité peut toucher :

- audition ;
- équilibre.

Signes :

👂 acouphènes

🌀 vertiges

📉 baisse auditive

🫘 créatinine ↑

🚽 diurèse ↓.

🧠 Mémo :

# **AMINOSIDE = OREILLE 👂 + REIN 🫘**

## 🧪 Dosages plasmatiques

Selon le traitement et le protocole :

- concentration résiduelle ;
- parfois pic/concentration maximale ;
- fonction rénale.

🎯 Objectif :

**efficacité sans accumulation toxique.**

# 🧬 3. FLUOROQUINOLONES → ADN

Exemples :

- ofloxacine ;
- ciprofloxacine ;
- lévofloxacine.

Elles inhibent des enzymes bactériennes indispensables :

- **ADN-gyrase** ;
- **topoisomérase IV**.

Donc :

**fluoroquinolone → ADN impossible à dérouler/répliquer → bactérie ne peut plus se multiplier correctement → mort**

🧠 Image :

L’ADN est une **fermeture éclair 🧬**.

La quinolone bloque le curseur.

## 🚨 Fluoroquinolones = effets indésirables particulièrement importants

### 🦵 Tendinite / rupture tendineuse

Particulièrement :

**tendon d’Achille**

Une tendinite ou rupture peut apparaître précocement et parfois plusieurs mois après exposition.

Risque augmenté notamment avec :

- âge ;
- insuffisance rénale ;
- transplantation ;
- corticoïdes associés.

### ⚡ Neuropathies périphériques

- brûlures ;
- fourmillements ;
- engourdissement ;
- faiblesse.

Certaines atteintes peuvent être **persistantes ou potentiellement irréversibles**.

### ❤️ QT

Certaines fluoroquinolones peuvent :

**allonger QT → risque de torsades de pointes chez personne à risque**

### 🧠 Neurologique

Possibles :

- agitation ;
- confusion ;
- convulsions ;
- troubles psychiatriques selon contexte.

### 🍬 Dysglycémies

Hypo ou hyperglycémies possibles selon molécule et terrain.

🧠 Mémo :

# **QUINOLONE = TENDON 🦵 + NERFS ⚡ + QT ❤️**

# 🏭 4. MACROLIDES ET APPARENTÉS → PROTÉINES

## Macrolides

### Azithromycine

### Clarithromycine

Ils se fixent sur la sous-unité :

# **50S du ribosome**

➡️ inhibition de la synthèse protéique.

➡️ généralement **bactériostatiques**.

🧠 Mémo :

**MACRO = MACHINE 50S 🏭**

## ⚠️ Risques macrolides

- troubles digestifs ;
- atteinte hépatique ;
- **allongement QT** ;
- interactions médicamenteuses.

### Clarithromycine = interactions

La clarithromycine est notamment impliquée dans de nombreuses interactions via le système **CYP3A4**.

👩‍⚕️ Réflexe :

**clarithromycine + polymédication = vérifier interactions**

## 🌿 Pristinamycine

La pristinamycine appartient aux **streptogramines**, apparentées fonctionnellement aux antibiotiques inhibant la synthèse protéique.

➡️ action sur le ribosome bactérien.

## 🦠 Clindamycine

La clindamycine est une **lincosamide**, pas un macrolide à proprement parler.

Elle inhibe également :

**ribosome 50S → synthèse protéique ↓**

🚨 Point majeur :

# **CLINDAMYCINE + DIARRHÉE = penser Clostridioides difficile**

## 🚽 Diarrhée sous antibiotique

Une diarrhée simple peut être un effet indésirable banal.

Mais alerte si :

- diarrhée importante ;
- diarrhée persistante ;
- douleurs abdominales ;
- fièvre ;
- sang dans les selles ;
- dégradation de l’état général.

👉 Penser notamment :

**colite à C. difficile**

⚠️ Elle peut survenir **pendant ou après** l’antibiothérapie.

# 🏭 5. TÉTRACYCLINES → 30S

### Doxycycline

Elle se fixe sur :

# **ribosome 30S**

et empêche l’ajout de nouveaux acides aminés.

➡️ synthèse protéique ↓.

➡️ effet surtout **bactériostatique**.

### ⚠️ Effets à retenir

☀️ **photosensibilisation**

🔥 irritation/œsophagite

🤢 troubles digestifs.

### 💊 Absorption et ions

Certains ions peuvent diminuer l’absorption digestive :

- calcium ;
- fer ;
- magnésium ;
- aluminium.

Ils forment des complexes avec la doxycycline.

🧠 Image :

**Doxycycline + Ca/Fe = ils s’agrippent 🤝 → absorption ↓**

⚠️ Respecter les recommandations d’espacement prévues par la prescription/RCP.

### 🔥 Prévenir l’œsophagite

👉 avaler avec suffisamment d’eau ;

👉 éviter de prendre la doxycycline immédiatement avant de s’allonger.

🧠 Mémo :

# **DOXY = SOLEIL ☀️ + ŒSOPHAGE 🔥 + CALCIUM 🚫**

# 🧱 6. GLYCOPEPTIDE → VANCOMYCINE

La vancomycine agit principalement sur les bactéries **Gram positives**.

Elle bloque la synthèse de la :

# **PAROI BACTÉRIENNE 🧱**

Elle est particulièrement importante dans la prise en charge de certaines infections à Gram positif résistantes, notamment selon documentation microbiologique.

## 💉 Administration IV

Pour les infections systémiques :

**vancomycine = perfusion IV**

⚠️ Pas en injection IV rapide.

Pourquoi ?

Une perfusion trop rapide favorise une réaction liée à la perfusion :

- érythème ;
- prurit ;
- rougeur du visage et du tronc ;
- hypotension ;
- parfois dyspnée.

Historiquement appelée :

**« syndrome de l’homme rouge »**

👉 Il s’agit surtout d’une **réaction liée à la vitesse de perfusion**, différente d’une allergie IgE classique.

## 🫘 Toxicité rénale

Risque de :

**néphrotoxicité**

particulièrement avec :

- exposition importante ;
- insuffisance rénale ;
- autres médicaments néphrotoxiques.

### 🧪 Surveillance

Selon indication/protocole :

- créatinine / DFG ;
- concentrations plasmatiques de vancomycine ;
- efficacité clinique ;
- tolérance.

⚠️ Les modalités modernes de suivi peuvent reposer sur des objectifs pharmacocinétiques déterminés par les protocoles locaux ; ne pas appliquer un seuil universel sans prescription/protocole.

🧠 Mémo :

# **VANCO = VEINE LENTEMENT 💧 + REIN 🫘 + DOSAGE 🧪**

# 🏭 7. OXAZOLIDINONES → LINÉZOLIDE

Le linézolide se fixe au **ribosome 50S**.

Il empêche la formation correcte du complexe nécessaire au démarrage de la synthèse protéique.

➡️ protéines bactériennes ↓.

Particulièrement utilisé contre certaines bactéries **Gram positives résistantes** selon indication.

## 🚨 Risques essentiels

### 🩸 Myélosuppression

Possibles :

- anémie ;
- leucopénie ;
- thrombopénie ;
- pancytopénie.

👉 Le RCP recommande une **NFS complète hebdomadaire** pendant le traitement par linézolide.

🧠 Mémo :

**LINÉZOLIDE = LIGNÉES sanguines 🩸**

### 🧠 Syndrome sérotoninergique

Le linézolide possède une activité inhibitrice de la monoamine-oxydase.

Association avec certains médicaments sérotoninergiques :

➡️ risque de **syndrome sérotoninergique**.

Signes possibles :

- agitation ;
- confusion ;
- hyperthermie ;
- tremblements ;
- hyperréflexie ;
- tachycardie.

🚨 Urgence médicale.

### 👀 Neuropathie lors des traitements prolongés

Possibles :

- neuropathie périphérique ;
- atteinte du nerf optique.

🧠 Mémo :

# **LINÉZOLIDE = SANG 🩸 + SÉROTONINE 🧠 + NERFS 👀**

# 🍄 8. AZOLÉS → FLUCONAZOLE

⚠️ Le **fluconazole n’est pas un antibiotique antibactérien**.

C’est un :

# **ANTIFONGIQUE AZOLÉ 🍄**

Il inhibe une enzyme fongique intervenant dans la synthèse de :

**l’ergostérol**

L’ergostérol est un composant essentiel de la membrane du champignon.

Donc :

**fluconazole → ergostérol ↓ → membrane fongique perturbée**

🧠 Image :

La membrane du champignon est sa **combinaison de plongée 🤿**.

Le fluconazole empêche de fabriquer correctement le matériau de la combinaison.

## ⚠️ Risques

### 🫀 Hépatotoxicité

Surveiller selon contexte :

- ALAT/ASAT ;
- ictère ;
- nausées persistantes ;
- asthénie importante.

### ❤️ QT

Le fluconazole peut entraîner :

**allongement QT → torsades de pointes rares**

notamment avec facteurs de risque ou médicaments associés.

### 💊 Interactions

Le fluconazole inhibe plusieurs enzymes du cytochrome P450.

➡️ nombreuses interactions possibles.

🧠 Mémo :

# **FLUCONAZOLE = FUNGUS 🍄 + FOIE 🫀 + QT ❤️**

## 🧫 Prélèvements microbiologiques

Lorsque la situation clinique le permet :

# **PRÉLÈVEMENT AVANT ANTIBIOTIQUE**

Exemples :

- hémocultures ;
- ECBU ;
- prélèvement respiratoire ;
- prélèvement de plaie ;
- LCR selon indication médicale.

🎯 Objectif :

**identifier bactérie → antibiogramme → adapter le traitement**

⚠️ En urgence infectieuse grave, les prélèvements ne doivent pas conduire à retarder dangereusement une antibiothérapie urgente prescrite.

## 🎯 Antibiogramme

L’antibiogramme indique si la bactérie est sensible ou résistante aux antibiotiques testés.

🧠 Logique :

**infection → prélèvement → bactérie → antibiogramme → antibiotique le plus adapté**

🌱 C’est comme identifier précisément une plante invasive avant de choisir l’outil le plus ciblé plutôt que de traiter toute la forêt.
