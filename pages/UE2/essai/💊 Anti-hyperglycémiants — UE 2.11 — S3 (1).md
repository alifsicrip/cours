# 💊 Anti-hyperglycémiants — UE 2.11 — S3

## 🌿 Carte d’identité et grandes familles

Les **anti-hyperglycémiants** sont des médicaments qui diminuent une glycémie trop élevée.

👉 Ils sont principalement utilisés dans le **diabète de type 2**.

👉 Toutes les familles diminuent la glycémie, mais **elles n’agissent pas au même endroit**.

| Classe | Exemple | 🎯 Action principale | ⚠️ Risque à retenir |
|---|---|---|---|
| **Biguanide** | Metformine | ↓ production de glucose par le foie | Acidose lactique très rare |
| **Sulfamides** | Gliclazide | ↑ sécrétion d’insuline | **Hypoglycémie** |
| **Glinides** | Répaglinide | ↑ rapidement l’insuline autour des repas | **Hypoglycémie** |
| **iDPP-4** | Sitagliptine | ↑ effet des incrétines | Peu d’hypoglycémies seuls |
| **iSGLT2** | Dapagliflozine, empagliflozine | ↑ élimination urinaire du glucose | Déshydratation, acidocétose |
| **Agonistes GLP-1** | Sémaglutide | ↑ insuline, ↓ glucagon, ralentit l’estomac | Troubles digestifs |
| **α-glucosidases** | Acarbose | Ralentit l’absorption des glucides | Troubles digestifs |

**Voies :**

- 💊 principalement **orale** ;
- 💉 sous-cutanée pour certains agonistes du GLP-1.

## 🧠 Pharmacodynamie : comment font-ils baisser la glycémie ?

💡 **Pharmacodynamie = ce que le médicament fait au corps.**

Imagine la glycémie comme un **bassin qui contient trop d’eau**.

Pour diminuer son niveau, on peut agir sur plusieurs « robinets ».

### 🫀 1. Metformine → le foie

Le **foie fabrique du glucose**.

La metformine freine principalement cette fabrication.

➡️ Moins de glucose arrive dans le sang.

➡️ La glycémie diminue.

**Metformine → ↓ production hépatique de glucose → ↓ glycémie**

⭐ À retenir : elle ne stimule pas directement l’insuline.

👉 Donc **très peu d’hypoglycémies lorsqu’elle est utilisée seule**.

### 🧬 2. Sulfamides et glinides → le pancréas

Ils stimulent les cellules bêta du **pancréas**.

➡️ Le pancréas libère davantage d’**insuline**.

➡️ L’insuline favorise l’utilisation et le stockage du glucose.

➡️ La glycémie diminue.

**Sulfamide → ↑ insuline → ↓ glycémie**

⚠️ Problème : l’insuline peut devenir excessive par rapport aux apports alimentaires.

**Repas insuffisant + sulfamide → risque d’HYPOGLYCÉMIE**

### 🫘 3. iSGLT2 → le rein

Normalement, le rein récupère une partie du glucose filtré.

Les iSGLT2 diminuent cette récupération.

➡️ Plus de glucose part dans les **urines**.

➡️ La glycémie diminue.

**iSGLT2 → ↑ glucose urinaire → ↓ glycémie**

⚠️ À surveiller : déshydratation, infections génitales et rare **acidocétose**.

### 🍽️ 4. GLP-1 et iDPP-4 → les incrétines

Les **incrétines** sont des hormones digestives qui participent à la régulation de la glycémie.

Les traitements utilisant cette voie :

- augmentent l’insuline lorsque la glycémie est élevée ;
- diminuent le glucagon.

Les agonistes GLP-1 ralentissent également la vidange de l’estomac et diminuent généralement l’appétit.

➡️ **↓ glycémie**

### 🍞 5. Acarbose → l’intestin

L’acarbose ralentit la digestion des glucides.

➡️ Le glucose arrive **plus lentement** dans le sang après le repas.

➡️ Le pic glycémique est moins important.

⚠️ Cette action explique aussi les **flatulences et diarrhées**.

## 🧪 Pharmacocinétique et LADMER : que devient le médicament ?

💡 **Pharmacocinétique = ce que le corps fait au médicament.**

Le médicament entre dans l’organisme, circule puis est éliminé.

🧠 Pour retenir ce voyage : **LADMER**.

| Étape | 💊 Ce qui se passe | 👩‍⚕️ Pourquoi c’est important |
|---|---|---|
| **L — Libération** | Le principe actif est libéré du comprimé | ⚠️ Attention aux formes à libération modifiée |
| **A — Absorption** | Passage principalement de l’intestin vers le sang | Les repas peuvent modifier certaines prises |
| **D — Distribution** | Le médicament circule dans le sang | Il atteint son site d’action |
| **M — Métabolisation** | Plusieurs molécules sont transformées par le foie | Fonction hépatique et interactions à considérer |
| **E — Élimination** | Rein et/ou foie selon la molécule | Une insuffisance d’organe peut favoriser l’accumulation |
| **R — Réponse** | ↓ glycémie | Surveiller efficacité + effets indésirables |

### 🧪 Exemple essentiel : metformine

Après administration :

**💊 bouche → 🍽️ intestin → 🩸 sang → 🫘 rein → urines**

La metformine :

- est absorbée dans l’intestin ;
- est très peu métabolisée ;
- est éliminée **sous forme inchangée par les reins** ;
- possède une demi-vie plasmatique terminale d’environ **6,5 h** pour la forme de référence étudiée.

🚨 C’est un point fondamental :

**Insuffisance rénale → ↓ élimination → accumulation de metformine → ↑ risque d’acidose lactique**

👉 **METFORMINE = PENSER REIN.**

## 💊 Administration, contre-indications et interactions

### 💉 Administration sécurisée

Toujours appliquer les **5 B** :

- 👤 **Bon·ne patient·e**
- 💊 **Bon médicament**
- ⚖️ **Bonne dose**
- 💉 **Bonne voie**
- ⏰ **Bon moment**

➕ bonne **traçabilité**

➕ bonne **surveillance**

| Médicament/classe | Administration à retenir |
|---|---|
| **Metformine** | Généralement pendant ou à la fin des repas selon la forme |
| **Gliclazide LM** | Généralement au petit-déjeuner ; ne pas écraser/mâcher la forme LM |
| **Répaglinide** | Prise liée aux repas |
| **Acarbose** | Au début du repas |
| **GLP-1 injectable** | Sous-cutané selon dispositif et fréquence prescrits |

⚠️ La forme exacte et le **RCP** doivent toujours être vérifiés avant d’écraser, ouvrir ou modifier un médicament.

### 🚫 Situations à risque

| Situation | ⚠️ Risque | 👩‍⚕️ Réflexe |
|---|---|---|
| Metformine + **DFG <30 mL/min** | Acidose lactique | Contre-indication → vérifier/alerter |
| Metformine + déshydratation importante | Accumulation | Évaluer + alerter |
| Sulfamide + repas sauté | **Hypoglycémie** | Vérifier alimentation et glycémie selon contexte |
| iSGLT2 + déshydratation/maladie aiguë | Acidocétose/déplétion volémique | Surveillance + avis médical |
| Metformine + excès aigu d’alcool | Acidose lactique | Vigilance + alerte selon contexte |
| Corticoïdes | ↑ glycémie | Surveillance glycémique |
| Plusieurs traitements hypoglycémiants | Hypoglycémie | Surveillance renforcée |

⚠️ Les adaptations de doses dépendent de la **molécule, du DFG, de l’âge et de la prescription**.

L’infirmier·ère ne modifie pas seul·e la posologie.

## 😵 Effets indésirables, complications et urgences

### 😵 Les risques à associer aux classes

| Classe | Effets indésirables principaux | 🚨 Complication importante |
|---|---|---|
| **Metformine** | Nausées, diarrhées, douleurs abdominales | **Acidose lactique** très rare |
| **Sulfamides/glinides** | **Hypoglycémie** | Hypoglycémie sévère/coma |
| **iSGLT2** | Déshydratation, infections génitales | **Acidocétose** |
| **GLP-1** | Nausées, vomissements, diarrhées | Déshydratation et complications spécifiques |
| **Acarbose** | Flatulences, diarrhées | Troubles digestifs importants |

### 🍬 Hypoglycémie

🟡 **Premiers signes :**

- faim ;
- sueurs ;
- tremblements ;
- pâleur ;
- palpitations.

🟠 **Atteinte neurologique :**

- confusion ;
- comportement inhabituel ;
- troubles visuels ;
- somnolence.

🔴 **Urgence :**

- convulsions ;
- perte de connaissance ;
- coma.

🧠 Chaîne à retenir :

**Sulfamide → ↑ insuline → ↓ glycémie → hypoglycémie → surveillance glycémique + neurologique**

### 🚨 Acidose lactique sous metformine

Rare mais **très grave**.

Elle est favorisée notamment par une accumulation de metformine sur un terrain à risque.

Signes possibles :

- grande faiblesse ;
- troubles digestifs ;
- douleurs abdominales ;
- crampes ;
- respiration anormale ;
- hypothermie ;
- troubles de conscience.

**Insuffisance rénale/déshydratation → accumulation → acidose lactique → URGENCE**

## 👩‍⚕️ Surveillance et conduite infirmière

### 👀 Avant et pendant le traitement

| 👩‍⚕️ Je surveille… | 🎯 Pourquoi ? |
|---|---|
| 🩸 **Glycémie** | Efficacité + hypo/hyperglycémie |
| 🍽️ **Alimentation** | Repérer le risque d’hypoglycémie |
| 🫘 **Fonction rénale / DFG** | Important notamment avec metformine |
| 💧 **Hydratation** | Déshydratation = risque accru |
| 🧠 **Conscience** | Repérer une hypoglycémie sévère |
| 🤢 **Tolérance digestive** | Fréquente avec certaines classes |
| 💊 Traitements associés | Interactions |
| 📈 **HbA1c** prescrite | Évaluer l’équilibre glycémique à moyen terme |

### 🚨 Si complication suspectée

**1️⃣ SÉCURISER**

- installer la personne ;
- prévenir les chutes ;
- évaluer conscience, respiration et circulation.

**2️⃣ ÉVALUER**

- glycémie selon contexte/protocole ;
- TA, FC, FR, SpO₂ si nécessaire ;
- dernier repas ;
- dernière prise ;
- dose administrée ;
- diarrhées/vomissements ;
- hydratation ;
- traitements associés.

**3️⃣ ALERTER**

🚨 Médecin/équipe d’urgence selon gravité si :

- hypoglycémie sévère ;
- convulsions ;
- perte de connaissance ;
- détresse respiratoire ;
- suspicion d’acidose ;
- erreur importante de dose.

➡️ **SAMU-Centre 15** devant une urgence vitale selon le contexte.

**4️⃣ AGIR**

- rôle propre : sécuriser, observer, recueillir les données, surveiller, transmettre ;
- prescription : traitement correcteur et modification thérapeutique ;
- protocole : appliquer les conduites institutionnelles prévues, notamment pour l’hypoglycémie.

**5️⃣ TRACER ET TRANSMETTRE**

🗣️ **SAED**

- **S** = Situation
- **A** = Antécédents
- **É** = Évaluation
- **D** = Demande

## 🩺 Mini-situation clinique + mémo

Mme B., 82 ans, prend du **gliclazide**.

Ce matin, elle mange très peu.

À 11 h :

- 😰 elle transpire ;
- 😵 elle est confuse ;
- 👻 elle est pâle.

### ❓ Raisonnement

1. Quelle complication suspecter ?
2. Quelle donnée vérifier rapidement ?
3. Pourquoi son repas est-il important ?

### ✅ Correction raisonnée

👉 Suspecter une **hypoglycémie**.

Le gliclazide stimule la production d’insuline.

Mais Mme B. a très peu mangé.

Donc :

**💊 gliclazide → ↑ insuline + 🍽️ peu de glucose apporté → 🩸 ↓ glycémie**

👩‍⚕️ Il faut :

- sécuriser Mme B. ;
- évaluer son état neurologique ;
- contrôler la glycémie selon protocole ;
- appliquer la conduite prévue ;
- alerter selon la gravité ;
- surveiller ;
- tracer et transmettre.

### 🧠 Mémo express : F.I.R.E.

🔥 **FIRE = où peut-on agir sur le glucose ?**

- **F — Foie** → metformine
- **I — Insuline** → sulfamides/glinides
- **R — Rein** → iSGLT2
- **E — Estomac/intestin** → GLP-1/acarbose

### 🧠 Mémo surveillance : G.R.A.I.N.

- 🩸 **G**lycémie
- 🫘 **R**ein
- 🍽️ **A**limentation
- 😵 **I**ndésirables
- 🧠 **N**eurologique
