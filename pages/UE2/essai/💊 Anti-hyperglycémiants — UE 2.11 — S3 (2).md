# 💊 Anti-hyperglycémiants — UE 2.11 — S3

## 🌿 Carte d’identité

Les **anti-hyperglycémiants** diminuent une glycémie trop élevée. Ils sont principalement utilisés dans le **diabète de type 2**.

| Classe | Exemple | 🎯 Action | ⚠️ Risque clé |
|---|---|---|---|
| **Biguanide** | Metformine | ↓ glucose produit par le foie | Acidose lactique rare |
| **Sulfamides** | Gliclazide | ↑ insuline | **Hypoglycémie** |
| **Glinides** | Répaglinide | ↑ insuline autour des repas | **Hypoglycémie** |
| **iDPP-4** | Sitagliptine | ↑ effet des incrétines | Peu d'hypoglycémies seuls |
| **iSGLT2** | Dapagliflozine | ↑ glucose dans les urines | Déshydratation, acidocétose |
| **GLP-1** | Sémaglutide | ↑ insuline, ↓ glucagon, ralentit l'estomac | Troubles digestifs |
| **α-glucosidases** | Acarbose | Ralentit digestion des glucides | Troubles digestifs |

💊 Voie surtout **orale**. Certains GLP-1 sont 💉 **sous-cutanés**.

🎯 Effet recherché : **↓ glycémie → ↓ HbA1c → prévention des complications du diabète**.

## 🧠 Pharmacodynamie = ce que le médicament fait au corps

💡 Question : **où agit-il pour diminuer la glycémie ?**

### 🫀 Metformine → FOIE

Le foie fabrique du glucose.

La metformine **freine cette fabrication**.

**Metformine → ↓ glucose hépatique → ↓ glycémie**

👉 Elle ne stimule pas directement l'insuline.

➡️ **Très peu d'hypoglycémies lorsqu'elle est utilisée seule.**

### 🧬 Sulfamides/glinides → PANCRÉAS

Ils stimulent la libération d'**insuline**.

L'insuline permet de diminuer le glucose sanguin.

**↑ insuline → ↓ glycémie**

⚠️ Si la personne mange peu :

**↑ insuline + ↓ apports → HYPOGLYCÉMIE**

### 🫘 iSGLT2 → REIN

Le rein récupère normalement du glucose.

Les iSGLT2 diminuent cette récupération.

**↑ glucose dans les urines → ↓ glycémie**

⚠️ Risques : **déshydratation + infections génitales + acidocétose rare**.

### 🍽️ GLP-1 / iDPP-4 → INCRÉTINES

Les incrétines sont des hormones digestives qui participent au contrôle glycémique.

➡️ **↑ insuline si glycémie élevée + ↓ glucagon**

Les GLP-1 ralentissent aussi la vidange gastrique.

### 🍞 Acarbose → INTESTIN

Il ralentit la digestion des glucides.

**↓ arrivée rapide du glucose → ↓ pic glycémique après le repas**

⚠️ Flatulences et diarrhées possibles.

## 🧪 Pharmacocinétique + LADMER = ce que le corps fait au médicament

💡 C'est le **voyage du médicament dans l'organisme**.

**💊 Administration → 🍽️ absorption → 🩸 circulation → 🫀 métabolisme → 🫘 élimination**

| LADMER | À retenir |
|---|---|
| **L**ibération | ⚠️ Ne pas écraser une forme LM sans vérification |
| **A**bsorption | Souvent digestive |
| **D**istribution | Circulation dans le sang |
| **M**étabolisation | Souvent hépatique, variable selon la molécule |
| **E**limination | Rein et/ou foie |
| **R**éponse | ↓ glycémie + éventuels effets indésirables |

### ⭐ Metformine = exemple essentiel

Elle est :

- 💊 absorbée par l'intestin ;
- 🩸 transportée dans le sang ;
- très peu métabolisée ;
- 🫘 éliminée **inchangée par le rein**.

Donc :

**Insuffisance rénale → ↓ élimination → accumulation → ↑ risque d'acidose lactique**

🚨 **METFORMINE = TOUJOURS PENSER REIN / DFG.**

## 💊 Administration + situations à risque

### ✅ Sécurité = 5 B

**Bon·ne patient·e + bon médicament + bonne dose + bonne voie + bon moment**

➕ **traçabilité + surveillance**

| Situation | ⚠️ Risque / conduite |
|---|---|
| Metformine | Généralement pendant/fin du repas selon forme |
| Gliclazide LM | Généralement au petit-déjeuner ; ne pas écraser |
| Répaglinide | Prise liée aux repas |
| Acarbose | Début du repas |
| Metformine + **DFG <30 mL/min** | 🚫 Contre-indiquée |
| Metformine + déshydratation | ⚠️ Risque d'accumulation → alerter |
| Sulfamide + repas sauté | 🚨 **Hypoglycémie** |
| iSGLT2 + déshydratation/maladie aiguë | ⚠️ Déplétion volémique/acidocétose |
| Corticoïdes | 📈 Risque d'hyperglycémie |
| Plusieurs hypoglycémiants | 📉 Risque accru d'hypoglycémie |

⚠️ Les **posologies et adaptations** dépendent de la molécule, du DFG, de l'âge et de la prescription.

👉 L'infirmier·ère **ne modifie pas seul·e la dose**.

## 😵 Effets indésirables + urgences

| Classe | 😵 Effets principaux | 🚨 Danger à connaître |
|---|---|---|
| **Metformine** | Nausées, diarrhées | **Acidose lactique** rare |
| **Sulfamides/glinides** | Hypoglycémie | **Hypoglycémie sévère** |
| **iSGLT2** | Déshydratation, infections génitales | **Acidocétose** |
| **GLP-1** | Nausées, vomissements | Déshydratation |
| **Acarbose** | Flatulences, diarrhées | Intolérance digestive |

### 🍬 Reconnaître l'hypoglycémie

🟡 **Début :** faim, sueurs, tremblements, pâleur, palpitations.

🟠 **Aggravation :** confusion, comportement inhabituel, somnolence.

🔴 **Urgence :** convulsions → perte de connaissance → coma.

**Sulfamide → ↑ insuline → ↓ glycémie → signes neurologiques → 🚨 urgence si forme sévère**

### 🚨 Acidose lactique sous metformine

Rare mais **grave**.

Facteurs favorisants : accumulation, insuffisance rénale, déshydratation, hypoxie selon contexte.

Signes possibles :

- faiblesse importante ;
- troubles digestifs ;
- douleurs abdominales ;
- respiration anormale ;
- hypothermie ;
- troubles de conscience.

➡️ **Suspicion = urgence médicale.**

## 👩‍⚕️ Surveillance et conduite infirmière

### 👀 Surveillance quotidienne

| À surveiller | Pourquoi ? |
|---|---|
| 🩸 **Glycémie** | Efficacité + hypo/hyperglycémie |
| 🍽️ **Alimentation** | Risque d'hypoglycémie |
| 🫘 **DFG/fonction rénale** | Risque d'accumulation |
| 💧 **Hydratation** | Déshydratation = facteur de risque |
| 🧠 **Conscience** | Hypoglycémie sévère |
| 🤢 Tolérance digestive | EI fréquents |
| 💊 Traitements associés | Interactions |
| 📊 HbA1c | Efficacité à moyen terme |

### 🚨 Si complication

**1️⃣ SÉCURISER**

Installer la personne. Évaluer conscience, respiration et circulation.

**2️⃣ ÉVALUER**

🩸 Glycémie + constantes selon contexte + dernier repas + dernière prise + dose + hydratation + traitements associés.

**3️⃣ ALERTER**

🚨 Médecin/équipe d'urgence si :

- hypoglycémie sévère ;
- convulsions/coma ;
- détresse respiratoire ;
- suspicion d'acidose ;
- erreur importante de dose.

➡️ **SAMU-Centre 15** si urgence vitale.

**4️⃣ AGIR**

- 👩‍⚕️ **Rôle propre** : sécuriser, observer, surveiller, recueillir les informations, transmettre.
- 📋 **Prescription/protocole** : traitement correcteur, adaptation thérapeutique, conduite protocolisée.

**5️⃣ TRACER + TRANSMETTRE**

🗣️ **SAED = Situation → Antécédents → Évaluation → Demande**

## 🩺 Mini-situation clinique

👵 Mme B., 82 ans, prend du **gliclazide**.

🍽️ Elle mange très peu ce matin.

À 11 h : **sueurs + pâleur + confusion**.

### ❓ Que penser ?

👉 **HYPOGLYCÉMIE jusqu'à preuve du contraire.**

Pourquoi ?

**Gliclazide → ↑ insuline + repas insuffisant → ↓ glycémie**

### 👩‍⚕️ Que faire ?

**Sécuriser → glycémie selon protocole → conscience/constantes → rechercher dernière prise et dernier repas → appliquer protocole → alerter selon gravité → surveiller → tracer/transmettre.**

## 🧠 Mémo express

### 🔥 F.I.R.E. = où agissent-ils ?

- **F** = 🫀 **Foie** → metformine
- **I** = 🧬 **Insuline** → sulfamides/glinides
- **R** = 🫘 **Rein** → iSGLT2
- **E** = 🍽️ **Estomac/intestin** → GLP-1/acarbose

### 👩‍⚕️ G.R.A.I.N. = que surveiller ?

- **G** = Glycémie 🩸
- **R** = Rein 🫘
- **A** = Alimentation 🍽️
- **I** = Indésirables 😵
- **N** = Neurologique 🧠
