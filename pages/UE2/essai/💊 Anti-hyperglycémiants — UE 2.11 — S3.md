# 💊 Anti-hyperglycémiants — UE 2.11 — S3

## 🌿 Carte d’identité

| Élément | Informations |
|---|---|
| Principaux représentants | **Metformine**, gliclazide, répaglinide, sitagliptine, iSGLT2, agonistes du GLP-1, acarbose |
| Famille thérapeutique | Médicaments du **diabète de type 2** |
| Voies principales | 💊 Orale ; 💉 sous-cutanée pour certains agonistes du GLP-1 |
| Objectif | Faire diminuer une **glycémie trop élevée** |

Les anti-hyperglycémiants regroupent plusieurs familles.

👉 Ils ont le même objectif : **faire baisser la glycémie**.

Mais ils n’agissent **pas tous de la même façon**.

## 🎯 Indications et effets recherchés

| Indication | Effet recherché | Surveillance |
|---|---|---|
| **Diabète de type 2** | ↓ glycémie | Glycémies + HbA1c |
| Risque cardiovasculaire ou rénal chez certain·es patient·es | Protection supplémentaire avec certaines classes | Fonction rénale, TA, poids selon traitement |

🎯 Objectifs principaux :

- éviter l’**hyperglycémie chronique** ;
- réduire les complications du diabète ;
- atteindre un objectif d’**HbA1c individualisé**.

## 🧠 Pharmacodynamie : ce que le médicament fait à l’organisme

💡 Question simple : **où agit le médicament pour faire baisser le sucre ?**

| Classe | Où agit-elle ? | Action | Risque à retenir |
|---|---|---|---|
| **Metformine** | 🫀 Foie | ↓ fabrication de glucose | Acidose lactique très rare |
| **Sulfamides** | 🧬 Pancréas | ↑ sécrétion d’insuline | ⚠️ Hypoglycémie |
| **Glinides** | 🧬 Pancréas | ↑ rapidement l’insuline autour des repas | ⚠️ Hypoglycémie |
| **iDPP-4** | 🧠 Système des incrétines | ↑ insuline si glycémie élevée | Faible risque d’hypoglycémie seuls |
| **iSGLT2** | 🫘 Rein | ↑ élimination du glucose dans les urines | Déshydratation, acidocétose |
| **GLP-1** | 🧬 Pancréas + estomac | ↑ insuline, ↓ glucagon, ralentit l’estomac | Nausées, vomissements |
| **Acarbose** | 🍽️ Intestin | Ralentit l’absorption des glucides | Flatulences, diarrhées |

### 🧠 Exemple : metformine

Le foie fabrique naturellement du glucose.

La **metformine freine cette production**.

➡️ Moins de glucose arrive dans le sang.

➡️ La glycémie diminue.

**Foie → ↓ production de glucose → ↓ glycémie → meilleur équilibre du diabète**

Elle ne stimule pas directement l’insuline.

👉 Donc, utilisée seule, elle provoque **très rarement une hypoglycémie**.

### 🧠 Exemple : sulfamides

Les sulfamides stimulent le **pancréas**.

Le pancréas libère alors plus d’**insuline**.

L’insuline fait entrer le glucose dans les cellules.

➡️ La glycémie diminue.

⚠️ Mais si la personne mange peu ou saute un repas :

**trop d’insuline → trop peu de glucose sanguin → hypoglycémie**

## 🧪 Pharmacocinétique : ce que l’organisme fait au médicament

💡 Question simple : **que devient le médicament après son administration ?**

### 🧪 Metformine

1. 💊 Elle est avalée.
2. 🍽️ Elle est absorbée dans l’intestin.
3. 🩸 Elle circule dans le sang.
4. Elle est très peu transformée par le foie.
5. 🫘 Elle est éliminée principalement par les **reins**.

👉 Donc :

**rein malade → metformine moins bien éliminée → accumulation → risque d’acidose lactique**

| Paramètre | Metformine | Conséquence infirmière |
|---|---|---|
| Absorption | Digestive | Prise avec/à la fin du repas pour certaines formes |
| Tmax | Environ **2,5 h** pour certaines formes immédiates | Ce n’est pas la durée totale d’action |
| Métabolisme | Très faible | Peu transformée |
| Élimination | 🫘 Rénale | Surveiller le **DFG** |
| Demi-vie | Environ **6,5 h** | Peut augmenter si insuffisance rénale |

### 🧪 Sulfamides

Ils sont absorbés par l’intestin.

Ils sont ensuite surtout transformés par le **foie**.

Leurs effets peuvent durer plusieurs heures.

⚠️ Une hypoglycémie peut donc être **prolongée ou récidiver**, notamment chez une personne âgée ou fragile.

## 💊 LADMER simplifié

| Étape | À retenir |
|---|---|
| **L — Libération** | Attention aux comprimés à **libération modifiée** : ne pas les écraser sans vérification |
| **A — Absorption** | Souvent digestive |
| **D — Distribution** | Le médicament circule dans le sang |
| **M — Métabolisation** | Variable : foie pour plusieurs molécules |
| **E — Élimination** | 🫘 Rein important pour la metformine |
| **R — Réponse** | ↓ glycémie mais effets indésirables possibles |

🧠 Mémo : **LADMER = le voyage du médicament dans le corps.**

## 💉 Administration sécurisée

### ✅ Les 5 B

- **Bon·ne patient·e**
- **Bon médicament**
- **Bonne dose**
- **Bonne voie**
- **Bon moment**

➕ bonne **traçabilité**

➕ bonne **surveillance**

### 🍽️ Attention aux repas

- **Metformine** : souvent pendant ou après le repas pour améliorer la tolérance digestive.
- **Gliclazide LM** : généralement au petit-déjeuner selon prescription.
- **Répaglinide** : directement lié aux repas.
- **Acarbose** : au début du repas.

⚠️ Toujours vérifier le **RCP**, la prescription et la forme exacte du médicament.

## ⚖️ Posologies et adaptations

Les anti-hyperglycémiants n’ont **pas une posologie unique**.

La dose dépend :

- de la molécule ;
- de la prescription ;
- du **DFG** ;
- de l’âge ;
- de la tolérance ;
- des autres traitements.

### 🫘 Exemple important : metformine

| DFG | Conduite générale |
|---|---|
| ≥ 60 mL/min | Utilisation possible selon prescription |
| 45–59 mL/min | Dose maximale réduite selon RCP |
| 30–44 mL/min | Dose fortement limitée + surveillance |
| **< 30 mL/min** | 🚫 **Contre-indiquée** |

⚠️ L’infirmier·ère **n’adapte pas seul·e la dose**.

## 🚫 Contre-indications et précautions

| Situation | Risque | Conduite infirmière |
|---|---|---|
| Metformine + DFG <30 mL/min | Acidose lactique | 🚨 Vérifier et alerter |
| Déshydratation importante | Altération rénale | Surveiller TA, diurèse, état général |
| Sulfamide + repas sauté | Hypoglycémie | Vérifier alimentation + glycémie si indiqué |
| Infection aiguë sévère | Déséquilibre glycémique | Surveillance renforcée |
| Produit de contraste iodé + metformine | Accumulation si fonction rénale altérée | Suivre prescription/protocole |

## 🔄 Interactions importantes

| Association | Risque |
|---|---|
| Sulfamide + autre hypoglycémiant | ⚠️ Hypoglycémie |
| Metformine + alcool excessif | ⚠️ Acidose lactique |
| Corticoïdes | 📈 Hyperglycémie |
| Certains médicaments altérant le rein + metformine | Accumulation |
| Phytothérapie type millepertuis avec certains médicaments | Modification de l’efficacité |

👩‍⚕️ Toujours demander aussi les traitements pris en **automédication**.

## 😵 Effets indésirables

| Classe | Effets fréquents ou importants |
|---|---|
| Metformine | 🤢 Nausées, diarrhées, douleurs abdominales |
| Sulfamides/glinides | ⚠️ Hypoglycémie |
| GLP-1 | 🤢 Nausées, vomissements |
| iSGLT2 | 💧 Déshydratation, infections génitales |
| Acarbose | 💨 Flatulences, diarrhées |

### ⚠️ Signes d’hypoglycémie

- sueurs ;
- tremblements ;
- faim ;
- pâleur ;
- palpitations ;
- confusion ;
- comportement inhabituel ;
- somnolence.

🚨 Gravité :

- convulsions ;
- perte de connaissance ;
- coma.

## ⚠️ Complications et surdosage

| Complication | Contexte | Signes | Urgence |
|---|---|---|---|
| **Hypoglycémie sévère** | Sulfamide, glinide, insuline, repas sauté | Confusion, convulsions, coma | 🚨 Oui |
| **Acidose lactique** | Accumulation de metformine | Dyspnée, faiblesse, douleurs abdominales, altération neurologique | 🚨 Oui |
| **Acidocétose** | Possible avec iSGLT2 | Nausées, douleurs abdominales, polypnée | 🚨 Oui |
| Déshydratation | Diarrhées, vomissements, iSGLT2 | Hypotension, tachycardie, oligurie | ⚠️ Peut devenir urgente |

## 👩‍⚕️ Conduite infirmière en cas de complication

### 1. Sécuriser

- installer la personne en sécurité ;
- évaluer **conscience, respiration, circulation** ;
- ne pas administrer automatiquement une nouvelle dose si une complication grave est suspectée ;
- appliquer le protocole institutionnel.

### 2. Évaluer

Rechercher :

- glycémie ;
- TA, FC, FR, SpO₂ selon situation ;
- dernier repas ;
- dernière prise ;
- dose administrée ;
- diarrhées/vomissements ;
- fonction rénale connue ;
- traitements associés.

### 3. Alerter

🚨 Prévenir immédiatement le médecin ou l’équipe d’urgence si :

- hypoglycémie sévère ;
- convulsions ;
- coma ;
- détresse respiratoire ;
- suspicion d’acidose ;
- erreur de dose importante.

SAMU-Centre **15** si urgence vitale selon le contexte.

### 4. Surveiller

| Surveillance | Pourquoi ? |
|---|---|
| 🩸 Glycémie | Repérer hypo/hyperglycémie |
| 🧠 Conscience | Détecter aggravation neurologique |
| ❤️ TA + FC | Détecter déshydratation/choc |
| 🫁 FR + SpO₂ | Repérer détresse ou acidose |
| 🫘 Fonction rénale | Important surtout pour metformine |
| 🍽️ Alimentation | Important avec médicaments hypoglycémiants |

### 5. Tracer et transmettre

Utiliser **SAED** :

- **S** : Situation actuelle.
- **A** : Antécédents et traitement.
- **É** : Évaluation clinique.
- **D** : Demande ou conduite attendue.

## 🧬 Populations particulières

| Population | Vigilance |
|---|---|
| 👵 Personne âgée | Rein, alimentation, risque d’hypoglycémie |
| 🫘 Insuffisance rénale | Risque d’accumulation de certains médicaments |
| 🤰 Grossesse | Traitement choisi médicalement selon situation |
| 🍽️ Dénutrition/faible poids | Risque accru d’hypoglycémie avec sulfamides/glinides |
| 👶 Enfant | Indications limitées selon les molécules |

## 🩺 Mini-situation clinique

Mme B., 82 ans, reçoit du **gliclazide**.

Ce matin, elle mange très peu.

À 11 h, elle est pâle, transpire et semble confuse.

### ❓ Questions

1. Quel problème suspecter ?
2. Que vérifier en priorité ?
3. Quelle conduite infirmière adopter ?

### ✅ Correction raisonnée

👉 Suspecter une **hypoglycémie**.

Le gliclazide augmente l’insuline.

Si Mme B. mange peu :

**↑ insuline + ↓ apport de glucose = risque d’hypoglycémie**

👩‍⚕️ Vérifier :

- glycémie selon protocole ;
- conscience ;
- constantes si nécessaire ;
- dernier repas ;
- dernière dose.

Puis :

- sécuriser la patiente ;
- appliquer le protocole d’hypoglycémie ;
- alerter selon gravité ;
- surveiller ;
- tracer et transmettre.

## 🧠 Mémo express

### 🌟 F.I.R.E.

- **F — Foie** : metformine ↓ glucose fabriqué.
- **I — Insuline** : sulfamides ↑ insuline.
- **R — Rein** : iSGLT2 éliminent le glucose ; metformine éliminée par le rein.
- **E — Estomac/intestin** : GLP-1 et acarbose ralentissent l’arrivée du glucose.

### 👩‍⚕️ Surveillance = G.R.A.I.N.

- **G**lycémie
- **R**ein
- **A**limentation
- **I**ndésirables
- **N**eurologique

🌱 Image mentale : la glycémie est comme un bassin trop plein.

Les médicaments peuvent :

- fermer le robinet du **foie** ;
- utiliser davantage le glucose ;
- l’évacuer par le **rein** ;
- ralentir son arrivée depuis l’**intestin**.

## ✅ L’essentiel à retenir

| Question | Réponse express |
|---|---|
| C’est quoi ? | Médicaments diminuant l’hyperglycémie |
| Pourquoi ? | Contrôler le diabète de type 2 |
| Comment ? | Foie, pancréas, rein ou intestin |
| Risque majeur ? | ⚠️ Hypoglycémie pour certaines classes |
| Metformine : surveillance clé ? | 🫘 Fonction rénale |
| Que surveiller ? | Glycémie, alimentation, conscience, rein, tolérance |
| Quand alerter ? | Coma, convulsions, détresse, hypoglycémie sévère, suspicion d’acidose |

✅ **Metformine = penser REIN.**

✅ **Sulfamide = penser HYPOGLYCÉMIE.**

✅ **Repas sauté + sulfamide = danger.**

✅ **Toujours relier : médicament → mécanisme → risque → surveillance.**
